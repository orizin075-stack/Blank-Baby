# TUKUYO V1022.6.5 Gen4 Fusion Experimental

V1022.6.4 Fusion と、添付 V1022.6+gen4-dev を統合した派生研究版です。三方向差分の共通祖先は先の添付 V1022.6。V1022.6.4 までの日本語・数量役割・一次制約・観測選択・失敗後再計画・有限多項式研究・5スイッチ装置研究を保持し、第4世代の英語読み取りと形式問題言語 FPL を同じ CLI に接続しています。

通常の `think` は gen4 を既定にします。`--engine v1022` で従来の核、`--llm off` で外部教師を使わない運転を選べます。構造化観測や有限多項式の専用コマンドは既存の入口を保持します。`verified-query` の新しい G4 経路は外部教師を呼ばず、原文へ束縛した形式証明を別実装で再生します。`llm-ask` は両世代を local-first で使います。

G4 は数値・単位・式を厳密な分数で扱います。有限小数の表示も浮動小数点へ丸めません。形式検査の一意性は、非線形 Jacobian の局所 rank だけで確定せず、確定した変数へ段階的に代入できる大域的な一次制約から確認します。未証明の一般非線形問題は保留します。

教師の2つの読み方、または別の教師の一致を使う機構は添付版から継続しています。同じ数でも単位が違う合議は拒否し、競合した学習型は利用を停止します。同一 provider の2つの見方は独立教師とは扱いません。教師の一致と FPL 検算は、自然言語の翻訳が正しいことの完全な証明にはなりません。知識・会話の教師回答は unverified のままです。今回の融合で本物の Claude・ChatGPT・Gemini と対話したという主張はありません。

生きた個体の G4 学習型は署名付き commit、Whole State の head、transaction、checkpoint/restore に接続しました。学習ファイルのチェックサムだけを再計算した改変と、学習 namespace だけの古い状態への巻き戻しを拒否します。単体 `Store` のチェックサムは認証ではありません。旧 gen4-dev の未署名学習ファイルは自動承認しません。G4 の新しい型は公開文化継承へまだ接続しておらず、既存 v1022 公開技能の継承とは別です。

この版は EXPERIMENTAL です。親で再現した workspace 復元後の未来 commit 問題の根本原因は未確定です。今回の検証結果は外部の検証報告と evidence を参照してください。親 README・STATUS と benchmark の数値は歴史資料であり、この融合版での再測定値ではありません。任意の現実世界の研究、汎用知能、自己コード改変、24h、意識の成立は主張しません。
