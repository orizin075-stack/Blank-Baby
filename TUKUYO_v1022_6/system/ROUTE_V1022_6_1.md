# V1022.6.1 — Observation planning

V1022.6の連立・逆算に、答えを得るための観測選択を加えます。利用可能な観測候補と費用は外から与えます。未知値を先に読み、正解に都合のよい候補を選ぶことはしません。

例: `制約: A+B=10。Aは何？` に対して、合計の再観測（費用1）は目標に役立ちません。Aの直接観測（費用8）と差A-Bの観測（費用2）が利用可能なら、差を選びます。その後に差4という観測値を受け取り、A=7を別parserとproofで検査します。

```json
{"budget":10,"options":[{"id":"total","expression":"A+B","cost":1},{"id":"direct","expression":"A","cost":8},{"id":"difference","expression":"A-B","cost":2}]}
```

```sh
python -B run_tukuyo.py --runtime-trust-file ../TUKUYO_v1022_6_1_TRUST_ANCHOR.txt --data /local/path/my_tukuyo think '制約: A+B=10。Aは何？' --observation-options options.json
```

観測後に `{"difference":"4"}` をvalues.jsonへ書き、同じコマンドへ `--observations values.json` を追加します。値は計画を生成した後に読みます。Python APIでは `observation_reasoning.plan(query, task)` と `update(plan['proof'], values)` を使えます。

予算内で目標を一意にする組合せを全探索します。候補最大8、最大256集合、費用1〜100、予算0〜800です。同額なら候補数、IDの辞書順で決定します。既知の目標は観測0件、予算不足や無関係な候補だけなら答えを作らず保留します。2つ以上の観測が必要な場合も組み合わせます。

生成側は目標係数が条件と観測係数の張る空間に属するかを計算します。別checkerは独立の字句parserで入力を再読し、同じ条件を満たす2世界の差（零空間）に対して目標が変わらないかを計算します。より安い全組合せも調べ、最小費用を検査します。元のconstraints/constraints_verifyと数量意味・生命・復元コードは保持します。

観測対象・候補・費用を自分で無制限に発明する機能、現実への観測ツール実行、外部観測値の真偽認証はありません。明示有理数一次式のみで、人数などの整数領域を使う観測計画は対象外です。新規AI教師対話、汎用AGI、主観意識、自己コード改変、自然選択、長期無人運転の達成は主張しません。workspace復元問題も未解決です。
