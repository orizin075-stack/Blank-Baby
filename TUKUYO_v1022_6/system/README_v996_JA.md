# TUKUYO v996 — Conversational Grounding

自由入力の文章を bounded semantic appraisal に通し、呼び出し側から valence 数値を渡さずに heart / soul へ経験として接続する層。

- `conversation-ingest TEXT [--relation PEER]`
- 文面から relation、社会的損傷、支援、知識獲得、失敗、誓約を限定的に抽出
- derived utility → valence / importance → heart → soul → semantic record
- 一般言語理解や意識を主張しない
