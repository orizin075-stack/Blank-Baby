# V1022.6.4 融合の操作と境界

## 起動

```sh
python3 -B tools/verify_release.py . --trusted-pubkey-file /absolute/path/TUKUYO_v1022_6_4_TRUST_ANCHOR.txt
python3 -B run_tukuyo.py --runtime-trust-file /absolute/path/TUKUYO_v1022_6_4_TRUST_ANCHOR.txt --data /local/path/individual init
python3 -B run_tukuyo.py --runtime-trust-file /absolute/path/TUKUYO_v1022_6_4_TRUST_ANCHOR.txt --data /local/path/individual think -- 'りんごが12個あります。妹に5個あげました。あげたのは何個？'
```

配布systemの外へデータを置いてください。CLI出力の版は署名済みreceiptから読みます。添付版の同梱アンカーは外部で認証された発行者の証明として扱わず、この派生版をこちらの継続鍵で新規署名しています。

## 融合した経路

| 入口 | 中身 | 条件 |
| --- | --- | --- |
| think / verified-query / llm-ask の local-first | 場面・時間・文章題・論理・記憶・一次制約 | 型ごとの証明・数量役割検査 |
| think --observation-options / --observations | 静的観測選択と目標一意性 | 外部に与えられた測定候補 |
| think --research-capabilities / --research-events | 一次制約の逐次観測・失敗後再計画 | 外部観測JSON、世界認証なし |
| hypothesis-research / hypothesis-research-check | 係数候補の生成・識別と別実装checker | degree0〜2の宣言クラスに条件付き |
| research-run / research-audit / research-status | 5スイッチの未知装置、固定文法内の法則探索・保存 | 模擬世界の有限32入力 |
| metabolism-init --research-world | 研究による収入・energy・死・実後継と確認済み法則の文化継承 | 任意モード、有限環境 |

既存観測・仮説CLIは `ROUTE_V1022_6_1.md`〜`ROUTE_V1022_6_3.md`、装置研究は `README_CLAUDE_PATCH5_JA.md` と `README_CLAUDE_PATCH6_JA.md` の操作を継続します。親のレポートの実測値は親のものです。今回の測定値は添付の融合検証レポートを参照してください。

## 合格条件

両系統の回帰、質問役割と数量の誤承認抑制、元課題に束縛した証明、模擬研究と保存監査、実後継と資源保存、途中停止・復元、配布前後の署名とsource hashを確認します。未完了の長時間試験を完了扱いにしません。新規未知問題で誤承認が出た場合は検証記録へ残します。

## 限界

自然言語は有限の型で、Parser B と生成器を別コードにしても同じ誤解を防ぎ切る証明にはなりません。有限クラスの目標一致は、実世界の法則がクラス内にある証明とは異なります。研究文法や模擬世界は外部が設計しています。自己コード改変・新種の文法の発明・外部AI長時間教師対話・24h・意識は今回の成立主張に含みません。
