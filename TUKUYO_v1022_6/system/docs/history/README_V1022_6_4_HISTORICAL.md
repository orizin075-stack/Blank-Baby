# TUKUYO V1022.6.4 Fusion Experimental

添付の V1022.6（claude-patch3〜6）と、こちらの V1022.6.3 を共通の V1022.5 Fusion から三方向で統合した研究版です。詳細な操作と境界は `ROUTE_V1022_6_4.md`、親の識別は `META/FUSION_LINEAGE_V1022_6_4.json`、実測結果は配布に添付する検証レポートを参照してください。

質問の対象・人物・物・時点を扱う場面モデル、文章題・時間・論理・記憶の拡張、固定文法の隠れた装置研究を追加しています。既存の一次制約・目標一意性証明・観測選択・測定失敗後の再計画・有限多項式仮説識別も残しています。

確定回答には、その型に適した独立検査を使います。旧数量グラフと新 Parser B はそれぞれの対応範囲で検査し、比較可能な不一致は保留します。場面モデルの「最初の数」「相手の数」などは旧残数専用グラフへ無理に翻訳せず、役割を読む Parser B と場面証明の再生で確認します。コード分離は完全な意味理解の独立性を保証しません。

LLM の回答は関連する検証済み主張、未裏付け内容チェック、こちらの回答全体の根拠束縛を通します。無関係な正しい計算だけでは作り話を verified にしません。新しい外部 AI 教師との対話はこの融合で行っていません。

研究は二つあります。`hypothesis-research` は明示した有限多項式クラスと外部観測履歴に対する条件付き証明です。`research-run` は固定文法・5スイッチ32入力の模擬装置を自ら調べるプレビューです。後者は署名付き記憶・再訪・任意の代謝研究ニッチへ接続されています。任意の現実世界を研究できるという主張ではありません。

復旧基盤も維持しますが、今回の版で100回反復復元・24h運転を通したと事前に主張しません。意識・文字通りの魂・汎用知能・自己コード改変の成立も主張しません。
