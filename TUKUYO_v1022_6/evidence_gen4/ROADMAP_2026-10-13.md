## 1. 9.0 の一部：復元を 100 回（`system/tools/restore_cycles.py`）

一つの個体に、データのフォルダの外の正史（`TUKUYO_CANON`）を置き、回復用の点検点を取ります。1 回ごとに、個体を変え（自分で 1 問解く、体を休める）、5 回に 1 回は署名付きのファイルを 1 つ壊し、点検点に戻します（奇数回は最初の点検点、偶数回は最新の点検点。10 回ごとに新しい点検点）。戻すたびに次を確かめます。

- 正史が、戻した写しを「正史より後ろ」（`CANON_BEHIND`）と見分け、持ち主の承認（`identity-canon-adopt --yes`）までは変えさせない
- 承認のあと、`whole-audit` と `soul-identity-audit` が通る
- 個体の ID が同じで、全体の状態が点検点のものと同じ
- そのあとも生きて考えられる（1 問解ける）

**結果：100 回すべて合格**（うち 20 回は、ファイルを壊してから戻した）。正史の鎖も壊れていません（404 行：最初 1・復元 100・ふつうの手番 303）。100 回すべてで、戻した写しは承認まで止められました（`restore_cycles_100_r9_2026-10-13.json`）。

この 100 回の途中で、前からの不具合を 2 つ見つけて直しました。

1. **復元のあとに取った点検点に戻すと、そのあと何もできなくなる**（v1014 からの不具合）。点検点は、その前の復元の受領書（`v1014/LAST_RECOVERY_RECEIPT.json`）も持っています。戻すとき、戻す側が新しい受領書を書くので、「復元のあとの変化を止める見張り」（restore frontier）がそれを書き換えと見て、すべての命令を止めていました（最初の試行では 12 回目から失敗）。受領書は戻すたびに書き直されるものなので、見張りはこのファイルだけ点検点のバイトと比べないようにしました（`tukuyo_v1014/recovery.py`）。
2. **正史の「どこまで読んだか」の印が点検点に入り、戻したあとに見張りに止められる**（r8 の不具合）。印を正史の私的な場所（`canon/private/`）に移し、点検点にも戻す対象にも入らないようにしました。戻した写しは、中身が正史の前の行と同じかどうかで「後ろ」と見分けます。

**まだのこと**：24 時間・72 時間・7 日の実時間の連続稼働は、このセッションでは走らせていません。

## 2. 7.9 経験の真正性（`system/src/tukuyo_v1022/provenance.py`）

魂が取り込む経験の一つ一つに、**どこから来たか**を書くようにしました。書くのは、その経験を書き込む道筋の側で、頼む側ではありません。魂の出来事の鎖（ハッシュでつながった記録）の中に入るので、あとから書き換えれば鎖が切れます。

| 出どころ | 意味 | 入る道 |
|---|---|---|
| 実観測（observed） | 自分の観測装置の結果。3 つの領域の較正された装置の署名付きの読みと、別の検証者の受領書 | `experience-observed` だけ。証拠を確かめ直し、経験の中身は証拠から作る（頼む側は選べない） |
| 自分で確かめた（checked） | 自分の検査と親たちの一致が確かめたこと | 第4世代の生活 |
| 教師から（teacher） | 教師の言ったことを、自分で確かめずに取り込んだもの | 教師との対話 |
| 申告（told） | 誰かが「あった」と言ったこと。外では確かめていない | `soul-experience`・`heart-experience`・`heart-feedback`・会話（既定） |
| 自己申告（self_report） | 自分について自分が言うこと | 頼む側が選べる |
| 模擬（simulated） | 模擬の世界の中の出来事 | 研究の世界、生態系、検査用の筋書き |

**外で確かめられた経験は「実観測」だけ**で、それも証拠が成り立っている間だけです。監査が、署名付きの観測の記録から毎回作り直して確かめます（ラベルだけでは何も確かめたことになりません）。申告・模擬・自己申告の経験は、そのままのものとして残ります。それを実観測に変える道はありません（観測は自分の経験を新しく作り、1 つの結果は 1 つの経験にしかなりません）。個体自身が持つ鍵（その個体が動かしている生態系の個体の鍵も含む）は、外の証人として認めません。

**合格の実験**（`system/tools/experience_authenticity_experiment.py`、本物の命令で実行、費用 0）：

| 試したもの | 結果 |
|---|---|
| 本物の観測の結果（成功・失敗の 2 件） | 2 件とも実観測の経験になった（失敗はつらい経験として） |
| 申告・模擬・教師・自己申告として渡した経験 | それぞれのまま記録。外で確かめられた経験は増えない |
| 「observed」「checked」と名乗った経験（2 つの命令で） | 4 通りとも断った |
| 模擬の経験を観測として引用 | 断った（その結果は記録にない） |
| 登録していない鍵の受領書 / 署名のあとで変えた読み / 較正の期間の外の観測 / 1 つの観測への 2 つ目の受領書 | どれも観測の記録が受け取らない |
| 同じ結果を 2 回使う / 他の個体の結果 / でっち上げのハッシュ | 断った |
| 個体自身の鍵を検証者にした受領書（観測の記録は受け取る） | 経験にする段で断った（`EXPERIENCE_EVIDENCE_SELF_SIGNED`） |
| 記録の 1 行を「observed」に書き換え | 監査が見つけ、`whole-audit` が通らない |
| 本物の証拠を、作り話の中身（裏切り）の下に付ける（個体の鍵で署名し直しても） | 監査が見つけ（`EXPERIENCE_NOT_FROM_ITS_EVIDENCE`）、`whole-audit` が通らない |
| 対照：何もしない写し | 監査が通る（上の 2 つの検出が、写しのせいでないことの確認） |

**攻撃 19 通りで、外で確かめられた経験に上がったもの 0。本物 2 件と対照 1 件はすべて期待どおり。** 記録は、実観測・自己申告・教師・模擬を見分けて持っています（`experience_authenticity_r9_2026-10-13.json`）。

あわせて、証拠に縛られた魂（v1022.7）の判断の記録に「外で観測されたか」の欄（`decision_observation_statuses`）を足しました。自己申告だけの証言は、3 つの領域から署名されていても `SELF_REPORTED_ONLY` で、観測とはしません（これまでの欄は「誰が署名したか」の意味のまま残しました）。子の自己報告にも、経験の出どころの内訳が出ます。

**確かめていないこと**：観測装置の世界が現実の世界であること、設定した較正の機関が持ち主から独立していること（機関を登録するのは持ち主です）、観測されたことが真であること。

## 3. 8.1 経験から作る目標（`system/src/tukuyo_v1022/goals.py`）

目標は外から与えません。魂の記録（それまでの経験）から、少数のはっきりした決まりで作り、どの経験から来たかを持ちます。

| 目標 | 作られる条件 |
|---|---|
| 警戒する（guard_against:相手） | その相手との悪い経験（裏切り・害・その相手とした行動の悪い結果）が 2 回以上あり、良い経験より重い（最近のほど重い） |
| 信頼を取り戻す（rebuild_trust:相手） | 警戒していた相手との良い経験が、悪い経験に並んだ |
| 頼る（rely_on:相手） | その相手との良い経験が 2 回以上で悪い経験がない。または、取り戻したあと良い経験が倍を超えた |
| 探究する / あきらめる（主題） | 発見や良い結果が 2 回以上 / 探究していた主題で、最後の 2 回の結果が悪い |
| 誓いを守る | 誓い |

目標は選択に効きます（心の選択に、目標が触れる選択肢だけ、上限のある項を足す）。選んだ行動の結果を経験として取り込むと、目標が作り直され、変わったものは「作った・直した・やめた」と、そのきっかけの経験と一緒に台帳に残ります。監査は、記録から目標を作り直して台帳と比べます（台帳を書き換えると、個体の鍵で署名し直しても通りません）。

**合格の実験**（`system/tools/goal_formation_experiment.py`）：一つの個体を作ってバイトごと 2 つに写し（同じ始まり）、A は相手（peer-x）に 3 回裏切られ、B は 3 回助けられます。

1. 目標：A は「peer-x を警戒する」、B は「peer-x に頼る」（理由は、それぞれ 1〜3 番目の経験）
2. 仕事の場面（peer-x と組む / 一人で）：A は一人、B は peer-x と組む。**目標を外した心だけなら、2 体とも一人を選んだ**。分かれたのは目標による
3. 新しい場面（食べ物を peer-x と分ける / 取っておく）：A は取っておき、B は分ける（目標が別の場面にも及ぶ）
4. B が peer-x と組んで悪い結果になると、「頼る」をやめ（きっかけはその結果の経験）、次は一人を選んだ
5. A が peer-x に 3 回助けられると、「警戒」が「信頼を取り戻す」に直り、食べ物を分けるようになった（仕事は一人のまま）

監査は 2 体とも合格です（`goal_formation_r9_2026-10-13.json`）。検証が挙げた例（裏切りで警戒が高まり、協力が変わり、信頼が戻る経験で態度が再び変わる）を、そのまま確かめた形です。

**限界**：目標の種類と決まりは少数で、手で書いたものです。実験の経験は、命令で渡した「申告」の経験です。

## 4. 8.2 生活・社会・世代（生態系 `tukuyo_v1022.metabolism`）

これまで生態系は、作るときに 512 刻み・64 体までと決まっていました。今回、作るときに長さを選べるようにしました（最大 4096 刻み・256 体。前に作った生態系は前のまま）。途中で環境を変える命令（共有の資源の回復量を変える。干ばつなど）を足し、変えた時刻を記録します。個体には知らせず、出会わせます。

### 4.1 1,024 刻みの実験（4 家族、`system/tools/ecology_long_run.py`）

| 条件 | 結果 |
|---|---|
| 回復 3000／刻み、途中 400〜600 刻みで半分（学習あり） | **1,024 刻み・4 家族とも生存・32 世代**、継承 128 回、仕事の誤答 0、難しい仕事 445/445 正解。監査合格 |
| 同じ、学習なし | 1,024 刻み・4 家族とも生存・32 世代。難しい仕事は 144 回とも答えを控えて 0 回正解（簡単な仕事だけで暮らした）。監査合格 |
| 回復 3000、400 刻みから 200 刻みの間 回復 0（強い干ばつ） | 共有の資源 26.7 万が 528 刻みで尽き、**560 刻みで全滅**（16 世代） |
| 回復 1500（資源が少ない）、4 家族 | 4 体が同時に寿命を迎えたとき、資源が 4 体の後継に足りず、**64 刻みで全滅** |

学習は、収入の中身（難しい仕事で稼ぐか）を変えましたが、この条件では生死を変えませんでした。資源の回復が十分なら、学習なしでも暮らせたためです。

### 4.2 関係を足した：分け合いと共同の子育て（作るときに `--sharing`）

これまで個体どうしの関係は、共有の資源の取り合いだけでした。次の 2 つを足しました。どちらも、個体が自分の心で決めます。エネルギーは移すだけで、全体の量は変わりません（監査で確かめます）。

- **分け合い**：飢えている個体（3000 未満）がいると、一番満ちている個体（7000 以上）の心が、分けるか取っておくかを決めます。相手の飢えの深さと、それまでの相手とのつながり（魂の愛着）が「分ける」を押し、自分の損（余裕があるほど、残りの命が短いほど軽い）が引き止めます。助けられた側は「支え」の経験を、助けた側は「世話」の経験をし、つながりが育ちます。
- **共同の子育て**：死んだ個体の後継を、共有の資源で作れないとき、生きている個体に、自分のエネルギーを出して育てるかを聞きます（その死んだ個体とのつながり・残りの命が重みになる）。足りれば後継が生まれ、出した個体と子の両方に、そのつながりが経験として残ります。

| 条件（4 家族、1,024 刻み） | 分け合いなし | 分け合いあり |
|---|---|---|
| 資源が少ない（回復 1500） | 64 刻みで全滅 | **1,024 刻みまで続いた**（1 家系・32 世代・共同の子育て 1 回） |
| 強い干ばつ（400〜600 刻みで回復 0） | 560 刻みで全滅 | 560 刻みで全滅（違いなし。分け合いも子育ても起きなかった） |

資源が少ない条件では、64 刻みに 4 体が同時に寿命を迎えたとき、残りの命の短い個体たちがエネルギーを出し合って 1 体の子を育て、その家系が 1,024 刻みまで続きました（32 世代）。**関係が、全滅か存続かを分けました**（この条件で、ほかに違いはありません）。強い干ばつでは、全員が同じときに乏しくなり、分け合いも子育ても起きず、分け合いなしと同じ 560 刻みで全滅しました。どちらの実行も、エネルギーの保存と全体の監査は合格です（`ecology_eco1024_share_*_r9_2026-10-13.json`、分け合いなしの資源の少ない条件は `ecology_eco1024_scarce_no_sharing_r9_2026-10-13.json`）。

**限界**（測って分かったこと）：

- 生きている個体が子を増やす仕組みがない（後継は死んだ 1 体に 1 体）ので、一度減った家族は戻りません。
- 4 家族が同じ時刻に生まれ、同じ時刻に死にます。全員が同時に乏しくなるので、分け合える相手がいないことが多いです。
- エネルギーは共有の資源からしか得られません（探して新しい資源を見つける道がない）。強い干ばつは、エネルギーの総量の計算の上で越えられません。検証の言う「探索・工夫で生き方を得る」は、まだです。
- 実行は各条件 1 回ずつです。

## 5. 8.0 新しい非公開の問題での頭脳（`system/tools/private_eval.py`）

検証の 43 問の JSON はないので、同じ種類（日常の文章題）の問題を新しく書きました。公開の問題集からは取っていません。

**直す前（r8）**：本番用で英語の正解 28／60、日本語 20／60、誤答 0。開発用で英語 30・日本語 11、誤答が日英で 1 問ずつ（「14 人の男の子と何人かの女の子がいるクラス。クラスは何人？」に 14、「クラスに男の子が 14 人。クラスは全部で何人？」に 14）。

**直したこと**：
