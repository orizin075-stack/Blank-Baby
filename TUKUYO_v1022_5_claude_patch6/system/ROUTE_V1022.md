# v1022の段階と次の合格条件

点数や独自Lレベルを完成条件にしません。実測と非成立の境界を使います。

| 段階 | 実装 | 合格条件 |
|---|---|---|
| A 完全性・復元 | 継承子の既存鍵を復元stageへ保持。owner/childロック。署名状態と履歴の結合 | 全selftest、部分rollback拒否、強制終了rollback/redo、子を含むcheckpointの復元 |
| B 思考 | 局所算術、数量台帳、肯定多段推論、有限最小費用探索、別の証明検査 | 教師に非開示の数値転移、前提不足での保留、外部計算との比較 |
| C 対話学習 | 3教師役が実応答を読み追試。数量抽象化・語彙対応・出典付き事実 | 同じ実装のblank対照より未知入力を改善。誤承認を独立して数える。再起動後も学習を保持 |
| D 実代謝 | 実個体のHeart選択→課題成果→有限資源→実energy→不可逆死→署名実継承 | 学習/行動の対照、ENERGY死、資源保存、独立identity/keys、公開技能だけの継承 |
| E より広い学習 | 未実装 | 自由文からの前提抽出と矛盾解消を独立課題で改善。教師から答えだけを暗記しない |
| F 自己改変 | 未実装 | 別process・保護領域・独立試験・保留と復帰を持つ候補コードの検証。現在の規則更新と区別 |
| G 長期環境 | runnerあり、24h未完走 | 資源制限と対照を含む24h実時間、外部証跡、性能・故障・家系の統計 |

今版のDは設計された有限課題に閉じています。報酬条件も環境も外部実験者が決めます。本人が外界へ自由に働きかける段階ではありません。死亡後の後継しか作れず、生存親繁殖・非拘束の進化も未実装です。

v930からは、反例を試す、入力域を限定する、転移と保留を測る設計を参考にしました。v930のアーカイブを載せただけで最新機能へ自動昇格したとは扱いません。
