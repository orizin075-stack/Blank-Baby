# TUKUYO v1022.5 Fusion + claude-patch6（聞かれたことを読み、法則を組み立てる）

patch5 で「自分で実験を選び、法則を見つけて生き延びる」ところまで進みました。patch5 を確かめる中で、大きな弱点が 2 つ見つかりました。

1. **文章題で、聞かれていることを読んでいない。** 質問が「あげた数」「はじめの数」「相手の数」を聞いていても、残りの数を答えていました。しかも独立の読み取り（Parser B）も同じ読み方をするので、間違った答えに AGREE（独立の裏付け）が付いていました。
2. **研究エンジンは、手持ちの 492 法則の外にある法則を見つけられない。** 「言葉の外だ」と気づいて表で覚えるところで止まっていました。

patch6 は、この 2 つを中心に「頭脳（読む力・考える力）」と「性能（正しく答える数・生き延びる力）」を上げました。patch5 までの機能はすべて残しています。

## 1. 質問を読む（`situation.py`）

### 1.1 しくみ

文章題を、まず「場面」に組み立てます。

- **持ち物**：誰が（どこに）、何を、いくつ持っているか。「姉は 50 個、妹は 20 個」「電車に 42 人」「かきが 18 個とくりが 30 個」のように、持ち主や物が複数でも別々に覚えます。
- **出来事**：食べた・あげた・もらった・降りた・来た・使った・買った…。誰から誰へ動いたかも覚えます。
- **質問の役割**：質問だけを読んで決めます。

| 役割 | 例 | 答え方 |
|---|---|---|
| 残り | 残りは何個？ 今何人？ | 出来事を全部たどる |
| はじめ | はじめにあったのは？ | 最初の量 |
| 〜する前 | 買う前は何個？ | その出来事の直前まで |
| 出来事の量 | あげたのは何個？ 降りたのは何人？ | その出来事の量（何回もあれば合計） |
| 相手の量 | 妹は今何個？ | 相手の最初の量が分かるときだけ |
| 別の物 | （かきを食べた）くりは何個？ | その物だけをたどる |
| 合計 | 二人合わせて何枚？ | 全員分を足す |

### 1.2 答えない場合

読み切れないときは、答えずに理由を返します。

- 相手の最初の量が書いていない（「妹に 5 個あげました。妹は何個持っていますか？」）
- いつの量を聞いているか分からない（「5 個食べました。りんごは何個ありましたか？」）
- 「彼」「彼女」が誰か決まらない、持ち主が 2 人いるのに誰のことか分からない
- 量がぼかしてある（何個か・ぐらい・some）、否定されている、予定の話
- 別の人の別の在庫の話（「別の人が別の在庫から 3 個食べました」）
- 意味が文脈で変わる動詞（売る・返す・借りる・lost など）

### 1.3 古い答え方との関係

- 役割が「残り」「合計」以外のとき、または持ち物が 2 つ以上あるときは、場面モデルの答え（または「答えない」）を優先します。古い作り方は「残り」しか計算できないからです。
- 役割が「残り」のときは、今までの作り方を先に使います。今までの作り方が答えないときだけ、場面モデルが答えます。
- 両方が答えて数が食い違ったときは、意味の監査（semantic gate）を通る方を使います。どちらも通る、またはどちらも通らないときは、答えません（`PRODUCERS_DISAGREE`）。

## 2. 問題の型を増やす（`mathprob.py`）

### 2.1 型の一覧

| 型 | 例 |
|---|---|
| 平均 | 5回のテストの点数は64点、78点、90点、85点、73点。平均は？／気温（度）も |
| 面積・まわり | 長方形・正方形・三角形（cm²・平方センチメートルも読む） |
| 最小公倍数・最大公約数 | 8と12と20の最小公倍数／greatest common factor of 18 and 24 |
| 数列 | 等差・等比（4 項以上） |
| 割合 | 90個の3分の2、40人の60%、「30人のクラスで、そのうち5分の2が…」 |
| わり算 | あまり、全員が乗るには何台（切り上げ）、いくつできる（切り捨て） |
| 配り直し | 1人に5枚ずつ配ると4枚足りません。はじめに何枚？ |
| 1 つ分×いくつ分 | 1人に3本ずつ配ると何本いる／1列に7人ずつ並ぶと6列できた |
| 毎日の量 | 毎日3ページずつ、2週間で |
| 残りの人数 | 36人のうちめがねの人は9人。かけていない人は？ |
| ちがい・何倍 | ちがいは何個／AはBの何倍 |
| 年齢などの倍 | 母の年齢はわたしの3倍 |
| 値段 | 合計、おつり（あとから1000円札を出す形も）、残金、3個で210円のときの1個の値段 |
| 時間・速さ | 1時間20分の映画を2本、2時間で90kmの車の時速、travels 240 km in 3 hours |
| 英語 | groups, teams of 5, prices, budget, more/fewer than, I think of a number |

### 2.2 守っていること（fail closed）

- 質問の数は**全部**読む。読まない数が 1 つでもあれば答えない。
- 答えは正確な分数で計算する。人や物の数が整数にならないとき、円が整数にならないとき、割り切れない小数になるときは答えない（「50人の3分の1」「800円の3分の1」）。
- 答えが負になる（お金が足りない）ときは答えない。
- ぼかした量・予定・否定は答えない。
- 「49枚のカードを1人6枚ずつ配ると、何人に配れる？」は、patch3 の方針どおり答えません（全部は配れないので）。
- どの答えにも証明（型・式・使った数・単位）が付きます。`proofs.check` が質問を読み直して式を再計算し、改ざんした式や答えを見つけます。

## 3. Parser B（独立の読み取り、`semantic_gate.py`）

- **役割を読む**：質問が「あげた数」「はじめの数」などを聞いているとき、残りの計算に AGREE を付けなくなりました。patch5 で「間違った答えに AGREE」が出ていた原因です。
- **新しい型の読み取り器 13 個**：平均、最小公倍数、数列、面積、割合、わり算、配り直し、残りの人数、年齢の倍、速さ、毎日の量、硬貨と品物、英語のグループ。作る側のモジュールは import していません（patch4 のテストがそのまま検査します）。
- **英語の数詞**：Ten students の Ten も数として数えます。証明がこの数を使っていなければ、網羅の監査で止まります。
- AGREE の数（`think` で、作る側が確定した数の答えのうち、独立の読み取りが一致したもの）：

  | セット | patch5 | patch6 |
  |---|---|---|
  | 未見 F | 12/40 | **35/61** |
  | 未見 T | 14/17（**うち 9 件は誤った答え**） | **22/36（誤り 0）** |
  | 未見 C | 21/30 | 39/48 |
  | 未見 D | 17/23 | 22/28 |
  | 未見 E | 12/24 | 18/28 |

  - patch6 では、5 つのセットで AGREE が付いた 136 件に、誤った答えは 1 件もありませんでした。
  - patch5 の C・D・E は、patch5 の README に載っている数字です（同じ数え方）。

**正直に書いておくこと**：patch6 の読み取り器は、作る側と同じ私が書きました。コードは別々ですが、書いた人は同じです。

## 4. 論理と記憶

- **論理**（`logic2.py`）
  - 「明日晴れたら公園に行く。明日は晴れた。公園に行く？」のように、時の言葉を主語と間違えなくなりました。
  - 「泳げば疲れる。花子は泳いだ。花子は疲れた？」：主語のない一般の規則を、登場する人に当てはめます。
  - 「If Ken runs, he gets tired. Ken ran. Is Ken tired?」：gets tired を「tired である」と読みます。
- **記憶**（`kqa.py`）
  - 「青空美術館の館長といえば？」「政府が置かれた都市」（首都）、「何曜日が休み」（定休日）、「何語が話され」（公用語）などの言い換え。
  - 英語の in what year / what color。

## 5. 研究エンジン：法則を組み立てる（`invent.py`、`agent.py`）

### 5.1 文法

手持ちの部品（スイッチ・否定・かつ・または・排他）から、次の 5 つの形で法則を組み立てます。

| 形 | 例 | 数 |
|---|---|---|
| しきい値 | S1,S2,¬S4,S5のうち3つ以上 | 478 |
| ちょうど k 個 | ちょうど2つがオン | 6 |
| パリティ | S1⊕S2⊕S3⊕S4 とその否定 | 12 |
| 分岐 | S1ならS2∧S3、でなければ¬S4 | 14,170 |
| 2 つの組 | (S1∧¬S2)∨(S3∧S4) | 240 |

- 既知の 492 法則と同じ表になるものは除いて、**14,906 個**です。
- 文法は公開で固定です。**私が書いた文法の中で組み立てる**ので、新しい種類の法則を作り出すわけではありません。

### 5.2 いつ、どう使うか

- 「言葉の外」の確率が 0.9 を超えて表に切り替えたとき（patch5 の `METHOD_CHANGE`）に、証拠に一番よく合う法則を文法から選んで仮説に加えます。新しい入力を 6 つ見るか、観測が倍になるたびに、もう一度選びます。
- **事前確率**：文法全体で 0.05 を分け合います（既知の法則は 0.9、言葉の外は 0.1）。まず 5 つの形で等分し、形の中で等分します。データを見てから選ぶ分の代償を、ここで払っています。
- **主張の条件**：patch5 と同じ確認の手順（全入力 → 食い違いの再試験 → 環境が選ぶ入力での 10 回の再現 → 外れの再試験）に加えて、**仮説に加えていない文法の法則も全部数えた確信度**が 0.98 以上であること。足りなければ、競争相手を仮説に加えて、見分ける実験をします。
  - 例：「¬S1,…,¬S5のうち4つ以上」だけを仮説に持っていると、手元では確信度 1.00 です。文法全体では 0.012 です（「ちょうど1つがオン」が同じだけ合う）。そこで確認を始めず、「ちょうど1つがオン」を加え、次の実験に、2 つを見分ける唯一の入力を選びます（テストあり）。
- **満腹のときの好奇心**：表で覚えている間、エネルギーが上限からあふれそうなときだけ、いちばん分からない入力を調べます。あふれて捨てられるはずのエネルギーを使うので、ほぼただです。

### 5.3 段 5 の世界

文法の法則で、既知の 492 法則のどれとも 4 か所以上違うものです。4 つの形（しきい値・数え上げ・分岐・2 つの組）を同じ確率で選んでから、形の中で選びます。`research-run --tier 5` で行けます。

## 9. 限界

- 文章の読み取りは、今も有限の型です。型にない文、2 文以上にまたがる複雑な条件、図や表のある問題は読めません。読めないときは答えません。
- F・T も開発用の問題も、私が書きました。F・T の多くは開発用の問題と同じ型で、`mathprob.py` の説明の例には F とほぼ同じ文もあります（§6.1 の注意）。本当の意味での未見の評価には、別の人が書いた問題が必要です。
- F で答えられなかった 7 問の型です（F は調整に使わないので、直していません）：
  - 「〜より何冊多く**読みましたか**」（持ち物ではなく、した量の比較）
  - 2 段の「ある数」（「ある数から12を引いて3倍すると27」「ある数に4を足して2倍すると30」）
  - 「3000円の品物を2割引きで買いました。いくらで買いましたか」
  - 単価つきの 2 品の合計（「1個120円のりんごを5個と、1個80円のみかんを5個」）
  - 「1袋8個入りのみかんを5袋買って、6個食べました」
  - 「クラスの生徒は35人で、そのうち男子は18人です。女子は何人」

- センサーの誤り率の上限（10%）は、今も子に教えてあります。
- 本物の LLM での効果は、今回も測っていません。
- 長時間試験は 30 分です。24 時間の試験は、まだ実施していません。
