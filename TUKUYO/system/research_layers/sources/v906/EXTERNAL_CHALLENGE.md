# External challenge
1. Obtain the package through a channel independent of its embedded metadata.
2. Verify using a trusted release public key supplied out-of-band.
3. Run the package self-test and reproducer.
4. Record exact command, package SHA-256, result SHA-256, and execution timestamp.
5. Sign the receipt with the evaluator's own Ed25519 key.

This package does not claim that an external evaluator has completed these steps.
