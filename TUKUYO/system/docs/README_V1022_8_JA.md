# TUKUYO v1022.8 — 人物・品物・時点を追う頭脳

開発・実験版。基準はv1022.7.9です。ここでいう在庫の観測は問題文に書かれた前提であり、現実のセンサー観測を認証したという意味ではありません。

日英の有限な在庫文を、人物、品物、数量、出来事の実行状態、質問の時点を保持するプログラムへ変換します。数値の答えを記憶する表ではなく、一般化した規則と厳密な線形制約を使います。

## 新しい読解と検証

- 持っている数、増減した数、渡した相手を別々に追跡します。受取人の初期値を0と仮定しません。
- 数が不明な在庫や移動量は未知変数にします。後の在庫が明示されれば、初期値を逆算できます。
- 質問に無関係な未知変数を分離します。元の所有者の在庫が不明でも、固定された受取量と受取人の初期値から受取人の現在値を求められます。
- 同じ集団内の移動では総数を保存します。移動量が未知でも、初期の合計が分かれば最終の合計を求められます。
- 最初、現在、特定の買い物の後、特定の受渡しの前を区別します。同じ種類の出来事が複数あり、どれか決められない場合は保留します。
- 実行、否定、予定、能力、過去の実行が不確かな場合を区別します。不確かな既知量の出来事は、発生しなかったか指定量が発生したかを、最大8件の組合せについて検査します。
- 矛盾する在庫報告や、数量的に不可能な移動を拒否します。書かれていない行動の量を0と補いません。
- 不足している初期数量、発生の有無、どの出来事か等を`information_request`で返します。

生成側は`episodic_reader.py`と`episodic_fpl.py`です。別に実装した`episodic_verify.py`は、英語をトークン列、日本語を助詞・述語から解析し、生成側をimportせずに数値と対象を再計算します。従来のFPL計算・検算も併用します。同じ生成器を旧コアとG4の両方から呼んだ結果を、二つの独立した読解として数えません。

教師の形式的な計算が正しくても、質問が最初の数を聞いているのに最後の数を答える場合、あるいは品物と答えの単位が明確に食い違う場合は確定しません。教師間の一致だけを意味の証明としません。

## 通常の入口

```bash
python -B run_tukuyo.py --runtime-trust-file /path/TUKUYO_v1022_8_TRUST_ANCHOR.txt --data /path/individual init
python -B run_tukuyo.py --runtime-trust-file /path/TUKUYO_v1022_8_TRUST_ANCHOR.txt --data /path/individual g4-solve --llm off 'Nora has some pencils. Nora buys 5 pencils. Nora now has 17 pencils. How many pencils did Nora have at first?'
python -B run_tukuyo.py --runtime-trust-file /path/TUKUYO_v1022_8_TRUST_ANCHOR.txt --data /path/individual think --llm off '凛は鉛筆を17本持っています。葵は鉛筆を7本持っています。凛は葵に鉛筆を何本か渡しました。凛と葵の鉛筆は合わせて何本ですか？'
python -B run_tukuyo.py --runtime-trust-file /path/TUKUYO_v1022_8_TRUST_ANCHOR.txt --data /path/individual whole-audit
```

最初の問題は12、次の問題は24です。v7.8の共有台帳へ登録した個体は、引き続き台帳引数が必要です。v7.9の厳格な経験出所モードも個体ごとの明示設定を維持します。

## 範囲と合否

この読解は、明示された在庫文と質問を全て消費できる有限な文法に限ります。英語の数字表記は整数、日本語の個数単位は個・本・枚・冊・台を扱います。人物8、品物12、本文3000文字、前提32節、不確かな既知量の出来事8件までです。扱わない形式は従来の推論器へ戻ります。曖昧性を認識した形式は、他の読解で推測して確定しません。

日本語一般、複雑な文章題全体、自由な時間表現、金額・速度・比率の全てをこの読解で扱う版ではありません。共有する言語上の仮定もあるため、完全な意味解析の独立性を証明したとはしません。問題文の真偽、現実の統計的独立性、意識、文字どおりの魂、実LLMとの新しい教師対話、24時間運転、自己コード改変は未証明です。

開発用48問と、修正前に固定した転移評価80問を別々に測ります。後者は内部で作成した比較セットで、第三者の非公開試験ではありません。配布候補の全回帰、転移評価、性能、公開CLI、署名検証の実測値は別添の報告書で確認してください。STATUSの機能フラグから合格を推定しません。

旧単位表記の回帰1件は、ドル・菓子の同義表記をそれぞれ対応する問題文で試すよう、fixtureを修正しました。クッキーの質問に両教師がドルを答えても合格していた旧fixtureを、意味の正しさとして維持しません。代わりに、その誤承認を拒否する回帰を追加しています。試験削除やskipで合格させる変更ではありません。

G4では新読解器を`episodic_reader:stock_flow`という別の方法として記録し、旧読解器の経験を未検査の新しい方法への確認回数として流用しません。確信度試験は両方の方法を実際に模擬教師で確認するfixtureへ更新しています。版番号の試験も、過去の版の列挙から、署名receiptとの一致と版の形式を検査する方法へ更新しています。

金額や距離等の物理単位は、既存の単位付き読解・換算器へ明示的に渡します。新しい在庫文法で扱う品物の個数と混ぜません。

このパッチは既存の開発用鍵で署名します。元の発行者の承認を意味しません。
