# V1022.6.5 の操作

配布 `system/` の外へ個体データを置いてください。最初に新しい公開アンカーで配布を検証します。

```sh
python3 -B tools/verify_release.py . --trusted-pubkey-file /absolute/path/TUKUYO_v1022_6_5_TRUST_ANCHOR.txt
python3 -B run_tukuyo.py --runtime-trust-file /absolute/path/TUKUYO_v1022_6_5_TRUST_ANCHOR.txt --data /local/individual init
python3 -B run_tukuyo.py --runtime-trust-file /absolute/path/TUKUYO_v1022_6_5_TRUST_ANCHOR.txt --data /local/individual think --llm off -- 'Kim saw 4 cats in the morning. Later she saw one more cat. How many cats did she see in all?'
```

| 入口 | 動作 |
| --- | --- |
| think --engine gen4 --llm off | 両系統のローカル読みと形式検査 |
| think --engine v1022 | 以前の融合コア |
| g4-solve / g4-ask --llm off | FPL 読み取り、教師なし |
| g4-learned / g4-audit | 学習型の一覧・例の再生、live 状態では署名 head 検査 |
| verified-query | 元の質問に束縛した別実装の検算、外部教師なし |
| think --observation-options / --research-capabilities | 既存の観測・失敗後再計画 |
| hypothesis-research / hypothesis-research-check | 明示した有限多項式クラスに条件付き |
| research-run / research-audit | 固定文法の有限模擬装置研究と署名記憶 |
| metabolism-init --research-world | 任意の研究ニッチと実 runtime の代謝 |

教師の専用環境変数と録画再生の設定は `README_GEN4_DEV_PARENT_JA.md` を参照してください。この融合の測定は offline で、実 API の設定は行っていません。録画 fixture は人工応答であり、実教師の測定ではありません。

元の添付版とこの派生版の発行者鍵が違うときは、保存してある旧公開アンカーを `--previous-trust-file` に渡し、明示的に `runtime-trust-rebind` します。秘密鍵と学習内容を作り直す操作ではありません。元版の `g4/learned.json` だけに存在する未署名学習は、出所の再検証が必要なため自動移行を拒否します。
