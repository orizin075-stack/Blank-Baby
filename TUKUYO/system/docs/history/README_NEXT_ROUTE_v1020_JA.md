# 次ルート — v1020 Population Ecology / Multi-Lineage Selection

v1019は単一lineage内のbounded generational evolutionを成立させる。v1020では複数family lineageを同一有限環境へ置き、資源制約・協力・競争・繁殖機会・絶滅を含むpopulation-level selectionへ進む。

必須条件: population size上限、資源budget、複数環境、family間のidentity/key分離、fitness以外の多様性指標、単一traitへの崩壊防止、private Soul非共有、selection/reproductionの監査可能性。自然選択そのものを確立したとは主張せず、bounded artificial ecology assayとして評価する。
