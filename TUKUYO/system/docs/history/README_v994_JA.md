# TUKUYO v994 — Bounded Constructive Semantics

v994は、v978の少数の`kind`→単一意味対応を補う、限定的な構成意味層です。日本語・英語の複数cueを同時に拾い、epistemic / betrayal / support / integrity threat / commitment / truth / resourceなどの特徴を**一つに潰さず意味profileとして合成**します。否定・失敗表現はdomainを消さずにmodulationし、SOUL_COREが既に獲得したtheme/vow語彙もself relevanceとして参照します。relationが指定されればv993のrisk/attachment文脈も別特徴として束縛します。

例: `learning`, `study`, `research`, `発見`, `証拠を観察して研究する`はいずれもepistemic featureを持ちます。`証拠を発見できなかった`はepistemic domainとNEGATED_OR_FAILED_OUTCOMEを同時に持ちます。

`semantic-record`は解釈時のcontext snapshot、参照SOUL_EVENT、解釈結果をhash chainへ保存し、auditで再演します。

境界: 語彙・合成規則は有限です。自由言語一般理解、未知概念の自律的意味獲得、LLM級意味理解を主張しません。
