# OROR War × Nightfall Reborn v0.17.3 変更点

## 武器が全部「剣」だった問題を修正（武器の種別）
- これまで聖遺物の武器・伝説・残響（ダンジョン聖遺物）と、Nightfall融合版の武器は、見た目が槍でも弓でも杖でも
  中身はすべて「剣」でした。武器ごとに種別を付け、使い心地を変えました（種別は3Dモデルの形に合わせています）。
  - 近接：刀（炬珀）、剣（アインソフオウル、救堕せし勇者）、大剣（天輝、デミウルゴス）、大鎌（ルシファーラ）、
    輪刃（ウロボロス）、刺突（シンラの日傘、戒進の研究の注射器）、長柄（皇玲華・ヘファイストス・淵煌・エオマイア・メルス）、
    鈍器（ヴァレリア・クールマ・凄惨たる暴虐）、玩具槌（ノルティア）、拳（ベーリット・辿迦・獄華）、
    鞭・鎖（アンラマンユ、マグナ・マーテル、外悪の魔導）
  - 攻撃速度・威力・間合い（リーチ）・吹き飛ばし・なぎ払いの有無が種別ごとに違います。
    例：拳は超高速の連打で間合いが短い、長柄と鞭は間合いが長くなぎ払い無し、鈍器は遅いが重く強く吹き飛ばす。
  - 弓（テイア）：右クリックで引いて離すと矢を放ちます。矢は不要。伝説の弓は3本同時に放ちます。
  - 魔導具（理覇・カオス・エルセリア・メルリヌス・メアリー・スー・バハムート・ヌン・アルカナ・イグドラシル・
    御世姫命・無垢なる全能・邪沌の呪詛・甘契の未怪）：右クリックで魔弾を撃ちます。殴りは弱めです。
  - 連射砲（フェルディナント）：右クリック長押しで連射。砲（覇極）：着弾で炸裂する砲弾。
  - 盾（セイヴァー）：右クリックで構えてガード、盾で殴ることもできます。盾は壊れません。
  - 弓・魔導具・連射砲・砲・盾は「しゃがみ＋右クリック」でアーツを使います（右クリックは射撃や防御のため）。
    これらのアーツの再使用待ちは、使おうとしたときに画面下に「アーツ再使用まで○秒」と表示します。
  - それ以外の近接武器はこれまで通り右クリックでアーツです。
- 伝説の武器は同じキャラクターの武器の覚醒形なので、武器と同じ種別です。残響（ダンジョン聖遺物）も同じです。
- Nightfall融合版の武器33種も名前に合わせて種別を付けました（太刀・刀は刀、槍・ハルバードは長柄、斧は鈍器、
  短剣は刺突、爪は拳、大剣は大剣、棘車輪は輪刃、それ以外は剣）。
- 説明欄に種別と操作方法を表示します。
- 敵が学習する「プレイヤーの戦い方」も、持っている武器の種別（剣・斧・メイス・弓・素手）で判断するようにしました。

# v0.17.2 変更点

## 重大な不具合の修正（キャラクターが表示されない／リソースパックが外れる）
- v0.17.0〜v0.17.1 で、起動時に「Caught error loading resourcepacks, removing all selected resourcepacks」となり、
  `RigModel` の読み込みで `Expected a double but was BEGIN_ARRAY … bones[31].p` のエラーが出ていた不具合を修正しました。
  - 原因：髪の房の骨の設定に、描画用の方向（3つの数値の組）が誤って混ざっていました（ゲームは数値1つだけを想定）。
  - 骨の設定は数値だけを書き出すようにし、数値以外が混ざると書き出し時点で止まる検査を入れました。
  - さらに、ゲームと同じ方法（Gson・同じデータ型）で `rigs.json` を読み込む検査と、モデルデータの読み込み検査を
    毎回のビルドで実行するようにしました。
- 見た目は v0.17.1 と同じです（マイクラ本来の描き方の顔、立方体ベースのモデル）。

# v0.17.1 変更点

## 顔をマイクラ本来の描き方に作り直し
- バニラのプレイヤースキン（スティーブ・アレックス・アリ・エフェ・カイ・マケナ・ヌール・サニー・ズリ）と村人・イリジャーの顔を
  1ドットずつ調べ、その描き方に揃えました（v0.17.0の16×16ドットの細かいアニメ目は廃止）。
  - 顔は8×8ドット。目は4段目に「外側が白・内側が瞳」の横2ドット。まつ毛やハイライトは描きません。
  - 口は6段目中央の2ドットで、肌より少しだけ濃い色（女性・子供はアレックスやアリのように、ほんのりピンク）。
  - 髪は上の1〜3段と、長髪なら左右の端の列。帽子レイヤー（髪の厚み）もバニラと同じ1ドット単位。
  - 個性はバニラの文法の範囲で表現：瞳の色、光る目（ドラウンドのように）、子供や大きな目は瞳を縦2ドット、
    凛々しい／怒りの表情はイリジャーのような濃い眉、閉じた目、獣の目、ベール、眼鏡、片眼鏡、傷。
- 額の前に浮いていた立体の前髪の房は外しました（帽子レイヤーの前髪に統一）。

# OROR War × Nightfall Reborn v0.15.2 変更点

## 重大な不具合の修正（起動できない）
- v0.15.0〜v0.16.0 で「OROR Reborn — 41 Supreme Entities has failed to load correctly … CharacterRelicTooltips has no
  @SubscribeEvent methods」と表示されてゲームが起動しなかった不具合を修正しました。
  - 原因：作り直したクラスのイベント受信の印（@SubscribeEvent / @EventBusSubscriber）が、ゲーム実行時に見えない形でコンパイルされていました。
  - すべてのクラスの印を元のMODと照合する検査をビルドに追加し、同じ問題が再発しないようにしました。
- キャラクターの見た目は従来の箱型モデルです（v0.15.1の修正：まばたき・膝と肘の曲げ・手に持つ聖遺物の位置 は含まれます）。
