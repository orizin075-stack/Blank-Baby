# OROR War × Nightfall Reborn v0.16.0 変更点

## キャラクター46体を立体モデルで作り直し
- 箱を組み合わせた体から、なめらかな立体の体に変わりました（聖遺物の3Dモデルと同じ作り方）。
  - 人型30体：人に近い頭身（約5頭身）。頭は角を丸めた立方体に、マイクラ風のドット顔。首・肩・胸・くびれ・腰・長い脚・肘と膝・五本指の手・靴まで造形しています。
  - 髪は房ごとに立体（前髪・横髪・後ろ髪・ツインテール・ポニーテール・アホ毛）。揺れに合わせて二段階でなびきます。
  - 服も立体です。ひだのあるスカートとローブ（歩くと裾が広がる）、マント、着物の衿、袖、帯と結び目、肩当て、胸当て、頭巾、ストールなど。
  - 角・耳・尻尾・羽（羽根を重ねた翼、骨と皮膜の翼）・光輪（棘・多角形）・王冠・花冠・浮遊する宝石や星やカードも立体化しました。
  - クリーチャー・使い魔16体は、角を丸めた立体と2倍解像度の塗りに変えました。光輪・魔法陣・車輪は本物の輪になっています。
- 影（くぼみの暗さ）を形から計算してテクスチャに焼き込んでいます。発光部分だけを光らせる処理も軽量化しました。
- 前提MODの追加はありません（描画はMOD内で行います）。
- モデルの読み込みに失敗しても、ゲームが落ちないようにしています（その場合はログに警告が出ます）。

※ ゲーム内での表示確認はまだできていません。表示がおかしい場合は v0.15.1（従来の箱型モデル）に戻せます。
