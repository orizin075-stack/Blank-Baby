# OROR Nightfall 0.17.39-051-preview（050を土台）

050の続きです。050の内容（砲台168基・対空機関砲72基、A-10の自動着陸、滑走路まわりの伐採、生成済みの王都の更新など）は、そのまま入っています。詳しくは CHANGES_0.17.39-050_JA.md を見てください。

## 1. 爆発の破片が滑走路や畑に積もらないようにしました（「葉っぱが滑走路に突っ込んでいる」件の続き）
- 050では、滑走路のまわりの木を幹ごと切りました。それでも撮影で、滑走路や畑の上に葉や土のブロックが残っていました。
- 3回の撮影を比べると、これらは毎回違う場所にあり、斜めに傾いて浮いている物もありました。生えている木ではなく、爆発で飛び散った破片です。
  - 砲台の砲弾が畑や生け垣に当たると、壊れた葉・土・丸太・作物が「落下ブロック」として飛びます。
  - 落ちた所（滑走路の上など）で、そのままブロックとして積もっていました。
  - 050で砲台を増やしたので、破片も増えていました。
- 葉・土・丸太・作物のように、本来は落ちてこないブロックが落下ブロックとして出てくるときは、出現させないようにしました。
  - 爆発でブロックが壊れることは変わりません。壊れたブロックはそのまま消えます。
  - 砂・砂利・金床・コンクリートパウダーなど、本来落ちるブロックはこれまで通りです。
- 魔法使い（王国のメイジなど）の土魔法が出す岩の柱や破片は、見た目だけの一時的なもので、時間がたつと消えます。
