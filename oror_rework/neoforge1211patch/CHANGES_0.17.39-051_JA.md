# OROR Nightfall 0.17.39-051-preview（050を土台）

050の続きです。050の内容（砲台168基・対空機関砲72基、A-10の自動着陸、滑走路まわりの伐採、生成済みの王都の更新など）は、そのまま入っています。詳しくは CHANGES_0.17.39-050_JA.md を見てください。

## 1. 爆発の破片が滑走路や畑に積もらないようにしました（「葉っぱが滑走路に突っ込んでいる」件の続き）
- 050では、滑走路のまわりの木を幹ごと切りました。それでも撮影で、滑走路や畑の上に葉や土のブロックが残っていました。
- 3回の撮影を比べると、これらは毎回違う場所にあり、斜めに傾いて浮いている物もありました。生えている木ではなく、爆発で飛び散った破片です。
  - 砲台の砲弾が畑や生け垣に当たると、壊れた葉・土・丸太・作物が「落下ブロック」として飛びます。
  - 落ちた所（滑走路の上など）で、そのままブロックとして積もっていました。
  - 050で砲台を増やしたので、破片も増えていました。
- 葉・土・丸太・作物のように、本来は落ちてこないブロックが落下ブロックとして出てくるときは、出現させないようにしました。
  - 爆発でブロックが壊れることは変わりません。壊れたブロックはそのまま消えます。
  - 砂・砂利・金床・コンクリートパウダーなど、本来落ちるブロックはこれまで通りです。
- 魔法使い（王国のメイジなど）の土魔法が出す岩の柱や破片は、見た目だけの一時的なもので、時間がたつと消えます。

## 2. A-10の操縦（着陸）の見直し（ご要望：操縦技術）
050の最終ビルドでは着陸できましたが、051で試験を重ねると、帰り道や進入で失敗する回がまだ多くありました。記録から原因を1つずつ直しました。
- 滑走路の延長線に乗る飛び方：
  - これまでは、延長線上の「入口の点」（滑走路の手前150ブロック）をめがけて飛んでいました。
    - 入口は200ブロック手前、進入開始点は550ブロック手前に移しました。向きを変えた後のまっすぐな区間が長くなり、高さと速度を落としきってから入口に来ます。
  - 旋回で線から大きく外れると、点に斜めから近づいて線に乗れず、点のまわりを低く遅く回り続けて、丘に当たりました。
  - 延長線の上で、自分の位置より100ブロック先を目指して飛ぶようにしました。線から外れても、なめらかに線へ戻り、線に沿って入口まで来ます。
  - 延長線の上に出たら、遠くの進入開始点まで行かなくても、そこから線に乗り始めます。
- 速度と出力：
  - 帰り道の降下で出力を下げすぎると、次の旋回で出力が戻るのが間に合わず、速度が落ちて沈んでいました。
  - 帰り道では、出力を0.7（旋回中は1.0）より下げないようにしました。滑走路への降下中は、これまで通り出力で速度を調整します。
  - 延長線に乗った後の速度は1.5〜2.0にしました（1.15まで落ちて、線の横の木に沈んだため）。
  - 延長線に乗った後は、速すぎても降下します（速度を落とすまで水平に飛び続けて、入口に40〜60ブロックも高く来ていたため）。出力の下限は0.3です。
- 失速の防止：
  - 速度が1.2を下回ったら機首を下げて速度をつけ、1.6を下回っている間は3°より急には上昇しません。
  - 低速で機首を上げ続けて失速し、丘に落ちた回がありました。
- 進入：
  - 滑走路への降下は、中心線から15ブロック以内、向きの差20°以内に入ってから始めます（37ブロックずれたまま降下を始め、横の木に当たった回がありました）。
  - 降下中は、中心線からのずれと、横に流れる速さの両方を見て舵を当てます。
    - 中心線上の点を目指すだけだと線を行き過ぎ、反対側へ16ブロック流れて、進入路の横の木に翼を引っかけた回が2回ありました。
  - 延長線に乗った後は、滑走路より25ブロック上まで下ります。基準にするのは、延長線の真下の地面と、すぐ近くの地面です。
    - これまでは40ブロック横の丘を基準にしていたので、40〜58ブロックも高いまま入口に来ていました。
- やり直し（着陸の中止）：
  - 主翼を水平にしたまま全出力でまっすぐ上昇し、滑走路より40ブロック上に上がってから旋回します。
    - 降下中は出力がほぼ0です。すぐ低空で旋回すると速度を失い、滑走路の横の木に沈んでいました。
  - 接地点を少し過ぎても低ければ、滑走路の100ブロック目までは接地を待ちます。
- 帰り道で畑などに降りてしまったときは、地上係が自分の駐機場まで引いて戻します。
- CIの結果（最終ビルド）：
  - 飛行試験：戦闘のあと電池が減ると基地へ帰りました。滑走路に着陸して駐機場へ地上走行し、弾150発の補給と充電を受けました。無傷です。
  - 着陸の連続試験（下の3）：5回のうち3回、滑走路の上に中心線から2ブロック以内で接地し、無傷で止まりました。
    - 接地した位置は、滑走路の始まりから70・128・155ブロックの所です。
    - 1回は、やり直しを2回して試験時間（80秒）が終わりました。無傷です。
    - 1回は、滑走路の奥の端でやり直しの途中に沈んで接地し、体力の91%を失って滑走路の先まで出ました。
  - 調整の途中の結果（同じ5回の試験）：
    - 直す前：滑走路に降りたのは1回です（それもやり直し中に沈んで降りたもの）。
    - 入口を高すぎずに通るよう直した後：墜落は0回になりましたが、降りられたのも0回でした。
    - 区間を長くした後：きれいな着陸が1回、進入中に木に当たった墜落が2回でした。
    - 最終：上のとおりです。
  - まだ、着陸の失敗が5回に2回ほど残っています（やり直しで時間切れ、滑走路の奥での沈下）。

## 3. 着陸だけを続けて試す試験を加えました
- これまでのCIでは、1回の試験で着陸を1回しか試せませんでした。そのため、直した結果が良くなったのか、たまたまなのかが分かりませんでした。
- `/oror pilots landings` を加えました。飛行試験の滑走路で、着陸だけを5回続けて試します。
  - 毎回、電池が少なく弾のないA-10を、滑走路のまわりの空中に出します。
  - 出す場所と向き：
    - 滑走路の向こう端の先で、さらに遠ざかる向き
    - 滑走路の真横で、遠ざかる向き
    - 滑走路の手前の横で、遠ざかる向き
    - 進入路のずっと先で、滑走路へ向かう向き
    - 滑走路の上で、逆向き
  - そこから自分で帰って着陸します。毎回、次のことを記録します。
    - 滑走路の上に降りたか、どこに・中心線から何ブロックずれて降りたか
    - 接地の強さ、失った体力
- CIでは飛行試験のすぐ後に走ります。結果は上の2に書きました。

## 5. 王打倒のための武器（禁庫の武器）の見直し（ご要望：武器の確認とデザインの修正）
- 王殺しの5つの武器は、これまでネザライトの剣・斧、弓、弩、三叉槍に名前と印を付けただけで、見た目は普通の武器のままでした。
  - それぞれをOROR自身の武器にし、専用の絵（32×32のドット絵）を描きました。
    - 剣「界断」：黒いネザライトの大剣。刃の中心の溝に紅い炎のルーンが走り、つばはひびの入った金の王冠、柄頭に紅玉。
    - 斧「断罪」：処刑斧。細い首から大きく広がる刃の縁が紅く燃え、刃に炎の亀裂。背に金の棘、先に槍の穂先。
    - 弓「天穿」：黒い複合弓。両端は金、背に紅の象眼、弦が燃える。引き絞ると3段階で絵が変わり、紅い鏃の矢がつがえられます。
    - 弩「堕星」：金で留めた黒い台座に金の星。先端に鐙、弦は淡く光る。装填中の3段階、矢・花火を込めた状態で絵が変わります。
    - 三叉槍「海嘯」：黒い海鋼の三叉。湾曲した横木から返しの付いた3本の穂先が伸び、先が紅く光る。金の口金と深緑の柄巻。
  - 性能：剣は攻撃力10、斧は12（ネザライトより上）。弓・弩・三叉槍の耐久もネザライト級です。
    - これまで通り、村人王の結界を一撃で砕き、持ち主を蝕みます。
  - 禁庫にすでにある王殺しの武器（同梱セーブ・生成済みの王都）は、箱を開けたとき・持ったときに新しい武器に置き換わります。名前・エンチャントはそのまま引き継ぎます。
  - エンチャント台や金床でも、剣・斧・弓・弩・三叉槍として扱われます。クリエイティブの「戦闘」タブにもあります。
- 禁庫のほかの武器も、仮の絵のままだったので描き直しました。
  - 蒼珀の太刀（ただの水色の棒だった）：反りのある蒼い刀身に淡い刃文、琥珀の鍔、菱巻きの柄。
  - 星脈魔杖（金の矢印だった）：星の筋が光る黒木の杖。先に銀の三日月が星を抱く。
  - 夢幻処刑剣（ネザライトの剣の絵を借りていた）：細身のレイピア。刀身は先へ行くほど白く光る淡い紫。銀の護拳と紫の宝石。
- 王殺しの対物銃「穿界」と砲「終焉」は、Superb Warfareの銃（NTW-20、Secondary Cataclysm）のまま、名前と印で王殺しになっています。
