# OROR War × Nightfall 0.17.24 — 村の防衛・魔法武器・パリィ選択の修正

Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21。0.17.23（30MB以下のインポート版）を土台に、ORORのJARだけを差し替えた版です。
他のMOD・設定・Nightfall／Sword Soaringのセットアップ手順は0.17.23と同じです。

## 修正

- **村人が敵に気づかない問題**：0.17.22の待機AI間引き（5tickごと／遠方20tickごと）が、村人の警戒処理とずれていました。
  強い村人の索敵と、一般村人の危険察知はワールド時刻で10tickごとに行いますが、間引き後に処理が走るtickと重なるのは
  村人5人に1人だけでした。残りの村人は、敵が近づいても殴られるまで迎撃も避難もしませんでした。村人は間引きの対象から外し、
  0.17.21までと同じく毎tick判定します。他のモブの間引き（設定 idleAiInterval／distantAiInterval）はそのままです。
- **魔法武器の自動詠唱がマナ・クールダウンを無視していた問題**：TCRの魔法武器（magic_系）のダッシュ／空中攻撃で選択呪文を
  半分のレベルで発動する機能が、Iron's Spellsの通常詠唱が行う確認（マナ不足・クールダウン中・未習得）を通していませんでした。
  マナ0でも発動し、クールダウン中でも連発できました。通常詠唱と同じ確認を通し、発動できない場合は通常詠唱と同じ理由を
  アクションバーに表示します。
- **通常ガードを選び直しても基本パリィへ戻される問題**：ガード枠が通常ガードだと、1秒ごとに基本パリィへ付け替えていました。
  付け替えは各プレイヤー1回だけにし、その後スキル画面で通常ガードを選んだ場合はそのまま使えます。ガード枠が空なら
  これまでどおり基本パリィを装備します（config/oror-nightfall-patch.properties の basicParry=false で無効）。
- **名前が表示されなかった5アイテム**：The Incinerator Soulと4つの鞘に日本語・英語・中国語の名前を追加しました。

## 追加

- `SETUP_NIGHTFALL.cmd` を実行せずにゲームを始めた場合、ワールド参加時に「Nightfall／Sword Soaring が導入されていません。
  ゲームを終了し、このプロファイルのフォルダーにある SETUP_NIGHTFALL.cmd を一度実行してください。」と表示します。

## 導入

- 新しいプロファイル：`OROR_War_Nightfall_v0.17.24_Import.zip` を展開せずにCurseForgeへインポートし、起動前にプロファイルの
  フォルダーで `SETUP_NIGHTFALL.cmd` を1回実行します（0.17.23と同じ）。
- 0.17.23のプロファイルを使い続ける場合：ゲームとランチャーを終了し、`mods` の `oror_supreme_bosses-0.17.23.jar` を外して、
  `OROR_War_Nightfall_v0.17.24_Patch.zip` の `mods/oror_supreme_bosses-0.17.24.jar` を入れます。新旧のORORのJARを両方入れないでください。
  セットアップ済みならNightfall・Sword Soaringはそのまま使えます。

## 検証の範囲

- 変更した4クラスは、NeoForge 21.1.262と、パックと同じEpic Fight 21.17.3.1・Iron's Spells 3.16.3などの実JAR（CurseForgeから取得し
  SHA-256照合）に対してGitHub Actions上でコンパイルしました。ミックスインの対象メソッドが実JARに存在することも確認しています。
- JARは0.17.23の配布JARから、変更したクラスと翻訳だけを差し替えて作っています。他の約2000ファイルは同一です。
- 今回はゲームの起動・ワールドでのプレイ試験を行っていません。村人の迎撃、魔法武器の詠唱、パリィの切り替えは、
  ゲーム内で確認してください。
