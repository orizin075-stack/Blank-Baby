# OROR Nightfall 0.17.39-055-preview（054の続き）

054の続きです。054の変更点は、そのまま入っています（overrides/CHANGES_0.17.39-054_JA.md）。

## 1. 村人王の技に、1つずつ専用の動きをつけました（ご指摘）
### 054の問題
- 054では、武器ごとの10の技（70種）は効果も当たり方も別々でしたが、**体の動きは22種類の型を使い回していました**。
  - 弓の10の技は、見た目の動きが4種類しかありませんでした。
  - 大技も、特殊技10種のうち5種と、星墜とし・七つの鉢が、同じ「両手を掲げる」動きでした。
- 動きは「構え」と「打ち込み」の2コマだけで、脚・体のひねり・回転・連撃の振り分けがありませんでした。

### 055で変えたこと
- **70の技すべてと、自分の動きを持っていなかった大技など20種に、それぞれ専用の動きを作りました**（合わせて90種）。
- 1つの動きは、次のものでできています。
  - 構え、打ち込み、2撃目（連撃で左右を入れ替えるときなど）
  - 腕・前腕・胴（前屈み、ひねり、横曲げ）・頭（うなずき、振り向き、傾き）・脚（踏み込み、膝の曲げ）・体の回転・沈み込み
  - 武器の向き（刃や穂先を、世界の中でどちらに向けるか）
- **打撃が当たる瞬間に、振り抜きが合うようにしました**。
  - サーバーが打撃を入れる時刻（構えの終わり、連撃なら5ティックおき、射撃なら6ティックおき、跳躍の着地は12ティック後、引き寄せは8ティック後）に合わせて、腕を振り抜きます。
  - 連撃は、打撃の数だけ振ります（百裂なら10回、左右交互）。左右を入れ替えない連撃は、1回ごとに引き戻してから打ち直します。
  - 回転斬りは体ごと1回転（大鎌の大回転は2回転）し、終わったあと逆回しで戻ることはありません。
- 連撃の技は、最後の一撃まで動きが続くように技の長さを延ばしました（百裂 34→62ティック、多重斬り 26→36、欠損ブロック投げ 22→36、四連突き 22→30、双棍連打 26→30、二連斬 16→20）。
- 動きは、王のモデルそのものに当てて画像に描き出し、1つずつ確かめてから入れました（構え・打ち込み・2撃目を、斜め前と真横から）。連撃・回転・跳躍は時間を追って描き、振りの数と回り方を確かめました。

## 2. 蝿の帳を「場を覆いつくす」量にしました（ご要望）
- 054では、2〜3ティックに40粒ほどの黒い粒で、半径28ブロックの地面を覆うには薄すぎました。
- 055では、帳のあいだ次のようになります。
  - 2ティックごとに、帳の全面のあちこちに、蝿の群れ（黒い粒）を約400粒まき、墨のような靄も重ねます。
  - 帳の中にいる敵の体には、さらに濃い蝿の雲がたかります。
  - 蝿の眷属（ヴェックス）は、最初に8匹、3秒ごとに4匹ずつ増え、最大24匹になります。
- 帳の中の敵は、これまでどおり盲目・暗闇・毒になり、毎秒少しずつ喰われます。

## 3. 「飢え」：回復できなくなります
- このパックは Hunger Strike で満腹度がなくなっています（満腹度は減らず、食べ物は体力を回復します）。
  - そのため、054の「饗宴が満腹度を吸う」「空腹にする」は、実際には何も起きていませんでした。
- 055では、バアル＝ゼブルの「飢え」は、**しばらくのあいだ、どんな方法でも体力が回復しない**状態にしました（食べ物・再生・ポーションのどれでも）。
  - 饗宴：10秒
  - 疫病：8秒
  - 蝿の帳：帳の中にいるあいだ（毎秒2秒ずつ）
- 飢えたとき、画面に「飢え：しばらく回復できない」と出ます。
- 054のメモに書いた「疫病は回復を止める」は、実際には働いていませんでした（蝿がたかっているかを、回復のときに誰も確かめていませんでした）。055で、上のとおり働くようにしました。

## 4. 魂喰らいの鎖の切り方
- 王に3回攻撃を当てると鎖が切れます。054では、王の結界に吸われた攻撃や、威光ではじかれた攻撃は数えていませんでした。
- 055では、**結界に吸われても、はじかれても、王に当たった攻撃は数えます**。結界を割る手段がなくても、鎖は切れます。

## 5. 確かめ方を増やしました（CI）
王の物語の自動試験に、次のものを加えました。
- 崩壊王の結界を割ってから攻撃し、3回に1回すり抜ける（MISS）こと。
  - 054の試験では、結界が張られたまま攻撃していたので、MISSが一度も起きていませんでした（結界がMISSの判定より先に攻撃を吸うためです）。
- バアル＝ゼブルの結界を割ってから攻撃し、8回に1回、威光ではじくこと。
- 魂喰らい：
  - 魂の炎をつけた相手が王に3回攻撃を当てると、鎖が切れること。
  - もう一人は15秒燃え尽きて、魂を奪われること。
- 飢えた相手が回復しないこと。
- 蝿の帳で、眷属が増えていくこと。
