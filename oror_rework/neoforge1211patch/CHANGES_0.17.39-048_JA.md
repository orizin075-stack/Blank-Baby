# OROR Nightfall 0.17.39-048-preview（047を土台）

047の続きです。047で直しきれていなかったところを直しました。

## 1. 自然生成の王国が土に埋まっていたのを直しました（重大）
- 自然生成のグランドシタデルで、城の外周（滑走路・ヘリポート・戦車格納庫）、町の上空、外の砦などが、高さ80前後から約190まで土で埋まっていました。
  - 元のセーブには、建物の上の空っぽの部分のデータがありません。その「データのない部分」を、地下の土と同じ扱いで土で埋めていたためです。
  - 地面より上のデータのない部分は空（空気）として置くようにしました。城より高い山があれば、その部分も取り除きます。
- これが原因で、次のことが起きていました。
  - 城のヘリが高さ78付近で止まって上がれませんでした（土の天井）。
  - 城のA-10が滑走路から離陸できず（滑走路の上が土）、土の中に打ち出されて傷んでいました。
- **すでに生成済みのワールドの王国は直りません。** 新しく生成される王国（新しいワールド、またはまだ生成されていない場所）から直ります。同梱セーブの王国は元から埋まっていません。

## 2. アナイアレイターは砲台に置かず、禁庫へ
- 堡塁の砲台からアナイアレイターを外し、MK-42とMle 1934にしました（砲台の数は120基のまま）。
- アナイアレイターの設計図は、禁庫の「禁断の武具」の台座に必ず入れます。
- 王殺しの武具7種類（剣・弓・斧・弩・三叉槍・対物銃・砲）も、2つの台座に必ず全部入れます（047では確率で外れることがありました）。
