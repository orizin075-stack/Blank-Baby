# OROR Nightfall 0.17.39-052-preview（051を土台）

051の続きです。

## 1. ORORの技ごとに、動きと魔法の演出を多彩にしました（ご要望）
これまでは、41人それぞれに4つずつ（基本の技と3つの技）あるのに、動きは16種類しかありませんでした。123の技のうち49は、「詠唱」と「指差し」の2つの動きに集中していました。魔法の演出も、予兆は全員同じ（光の粒とエンチャントの文字）で、発動の演出もほぼエンチャントと会心の粒子だけでした。
- 技を使い始めた瞬間に、サーバーが「どの技か・予備動作の長さ・相手」を周りのプレイヤーに知らせます。画面側で、その技専用の動きと演出を再生します。
- 動き（24種類の仕組み＋基本の技3種）：
  - どの技も「振りかぶり→技が発動する瞬間に一気に振り抜く（少し行き過ぎて戻る）→残心→戻り」の流れです。
  - 例：斬撃は右肩から振りかぶって横一文字に薙ぐ。消去は両手を頭上から振り下ろす。反射は腕を胸の前で交差して払う。成長は地に手をついて、花開くように両手を空へ。巻き戻しは右手で時計の文字盤を逆向きに描く。封印は両手の掌を前へ押し出す。守りは腕を交差して足を開いて腰を落とす。転移は身を翻して回る。裁定は右手を天に掲げてから罪人を指す。召喚は両腕を大きく広げて浮き上がり、前へ振り下ろす。瞑想は宙に座して浮かぶ。連射は左右の腕を交互に突き出す。修復は鍛冶の槌のように打つ。吸収は手を伸ばして掴み、胸へ引き寄せる。呪いは背を丸めて手を垂らし、痙攣するように突き出す。
  - 腕のない竜や亀なども、予備動作で頭をのけぞらせ、発動で顎を開き、翼を広げ、尾を振ります。
- 武器ごとの型：
  - 同じ技でも、持っている武器で動きが変わります。剣は大きく薙ぎ、長柄は両手で突き込み、槌は頭上から叩きつけ、拳は踏み込み、鞭はしならせ、銃や弓は構えて反動を受けます。
  - 封印・回復・吸収のような「手で行う術」は、武器を持つキャラクターなら、右手で武器を構えたまま左手で行います。
- 魔法の演出（キャラクターごとの2色。テクスチャから色を取りました）：
  - 予備動作中は、足元に二重の魔法陣が回ります（外側と内側が逆向き）。文字が立ちのぼり、手に光が集まります。
  - 発動の瞬間は、技の仕組みごとに違う形です。斬撃の三日月、消去の白い光の柱、反射の六角の盾、成長の螺旋と花びら、巻き戻しの時計、天候の空からの光、封印の四角い紋、守りの半球、転移の門、裁定の光の柱と輪、適応の虹色の球、錬成の金の渦、召喚の魔法陣と五つの炎、魔力の螺旋、連射の光の筋、炸裂の衝撃波の輪、修復の火花と歯車、回復の立ちのぼる光とハート、吸収の赤い流れ、呪いの黒い渦、引き寄せの線、運命の札、複写の閃光、遊戯の紙吹雪です。
- 技の発動の瞬間と、動きが最大になる瞬間をそろえました（これまでは、技が出てから0.2秒ほど遅れて動きが最大になっていました）。
