# OROR Nightfall 0.17.39-052-preview（051を土台）

051の続きです。

## 1. ORORの技ごとに、動きと魔法の演出を多彩にしました（ご要望）
これまでは、41人それぞれに4つずつ（基本の技と3つの技）あるのに、動きは16種類しかありませんでした。123の技のうち49は、「詠唱」と「指差し」の2つの動きに集中していました。魔法の演出も、予兆は全員同じ（光の粒とエンチャントの文字）で、発動の演出もほぼエンチャントと会心の粒子だけでした。
- 技を使い始めた瞬間に、サーバーが「どの技か・予備動作の長さ・相手」を周りのプレイヤーに知らせます。画面側で、その技専用の動きと演出を再生します。
- 動き（24種類の仕組み＋基本の技3種）：
  - どの技も「振りかぶり→技が発動する瞬間に一気に振り抜く（少し行き過ぎて戻る）→残心→戻り」の流れです。
  - 例：斬撃は右肩から振りかぶって横一文字に薙ぐ。消去は両手を頭上から振り下ろす。反射は腕を胸の前で交差して払う。成長は地に手をついて、花開くように両手を空へ。巻き戻しは右手で時計の文字盤を逆向きに描く。封印は両手の掌を前へ押し出す。守りは腕を交差して足を開いて腰を落とす。転移は身を翻して回る。裁定は右手を天に掲げてから罪人を指す。召喚は両腕を大きく広げて浮き上がり、前へ振り下ろす。瞑想は宙に座して浮かぶ。連射は左右の腕を交互に突き出す。修復は鍛冶の槌のように打つ。吸収は手を伸ばして掴み、胸へ引き寄せる。呪いは背を丸めて手を垂らし、痙攣するように突き出す。
  - 腕のない竜や亀なども、予備動作で頭をのけぞらせ、発動で顎を開き、翼を広げ、尾を振ります。
- 武器ごとの型：
  - 同じ技でも、持っている武器で動きが変わります。剣は大きく薙ぎ、長柄は両手で突き込み、槌は頭上から叩きつけ、拳は踏み込み、鞭はしならせ、銃や弓は構えて反動を受けます。
  - 封印・回復・吸収のような「手で行う術」は、武器を持つキャラクターなら、右手で武器を構えたまま左手で行います。
- 魔法の演出（キャラクターごとの2色。テクスチャから色を取りました）：
  - 予備動作中は、足元に二重の魔法陣が回ります（外側と内側が逆向き）。文字が立ちのぼり、手に光が集まります。
  - 発動の瞬間は、技の仕組みごとに違う形です。斬撃の三日月、消去の白い光の柱、反射の六角の盾、成長の螺旋と花びら、巻き戻しの時計、天候の空からの光、封印の四角い紋、守りの半球、転移の門、裁定の光の柱と輪、適応の虹色の球、錬成の金の渦、召喚の魔法陣と五つの炎、魔力の螺旋、連射の光の筋、炸裂の衝撃波の輪、修復の火花と歯車、回復の立ちのぼる光とハート、吸収の赤い流れ、呪いの黒い渦、引き寄せの線、運命の札、複写の閃光、遊戯の紙吹雪です。
- 技の発動の瞬間と、動きが最大になる瞬間をそろえました（これまでは、技が出てから0.2秒ほど遅れて動きが最大になっていました）。

## 2. ORORのパリィを全モブに（ご要望）
ORORのパリィは、これまで次の相手にしか効いていませんでした。
- プレイヤー：Epic Fightのパリィ技（Nightfallのパリィ）。
- 敵：Epic Fight系の「Combat Evolution」「Indestructible」が設定されたモブと、王国の兵（村人王の配下）だけ。

それ以外のモブ（バニラの多く、他のMODのモブ、ORORの41人のキャラクター）は、パリィもガードもしませんでした。
- 王国の兵と同じ決まりで、全モブがガードとパリィをするようにしました。
  - 敵が5ブロック以内に来ると、ときどき構えます。
  - 構えた最初の3ティック（0.15秒）に正面から受けた攻撃はパリィします。攻撃は無効になり、スタミナの減りは攻撃の重さの5%です。
  - それより後に受けた攻撃はガードします。スタミナの減りは30%です。
  - スタミナが足りないとガードが崩れ、攻撃はそのまま入り、1秒よろけます。
- 強さで構え方が変わります。
  - ボス（ORORのキャラクター、ボス扱いのモブ、体力200以上）：1.8秒ごとに構えます。スタミナが多く、矢もはじきます。
  - 武器か盾を持つモブ：2.5秒ごとに構えます。剣などで矢をパリィし、盾なら矢もガードします。
  - 素手のモブ：3.5秒ごとに、短い時間だけ構えます。主にパリィで、ガードは攻撃を半分にするだけです。
  - 構えていないときに殴られると、次の構えが半分の時間で来ます（連続攻撃のリズムを読みます）。
- パリィされた側は、押し返されてよろけます。
  - Epic Fightのモブは、Epic Fightの長いよろけになります。
  - それ以外のモブは、ガードできなくなり、足が遅くなり、攻撃が弱くなります。
  - プレイヤーは、押し返されて少し遅くなるだけです。
- プレイヤーのパリィ（Epic Fight）も、全モブに効くようにしました。これまではIndestructibleのモブしかよろけませんでした。
- 見た目：
  - Epic Fightの人型のモブは、Epic Fightのガードとパリィの動きをします。
  - ORORのキャラクターと王国の兵は、専用の動きをします（パリィ・ガード・ガード崩れ・パリィされた、の4種類。武器ごとに違います。盾、両手の大きな武器、長柄、拳、魔法の手の守り）。
  - どのモブでも、パリィで閃光と火花、ガードで電気の火花、ガード崩れで破片が出ます。音も鳴ります。
- Combat EvolutionとIndestructibleのモブは、これまでどおりそちらのガードを使います（二重にはしません）。

## 3. 大技の動き（ご要望）
- ボスの大技（24種類）にも、それぞれ専用の動きをつけました。これまでは16種類の共通の動きを使い回していました。
  - 例：
    - 突進斬り：低く構えて刃を後ろに引き、踏み込みながら横に薙ぐ。
    - 連撃：3回、左右に切り返す。
    - 回転斬り：刃を水平に構えて2回転。
    - 跳躍叩きつけ：しゃがんで跳び、空中で両腕を振り上げ、着地とともに振り下ろす。
    - アッパー：低く沈んで拳を下に引き、空へ突き上げる。
    - 地割れ：片膝をつき、腕を地面に叩き込む。
    - 新星：身を丸めてから全身を開いて震える。
    - 竜巻：腕を広げて3回転しながら浮く。
    - 隕石：両腕を空に掲げてから、敵に向けて振り下ろす。
    - 光線：手を腰に引いてためてから、両手を突き出して撃ち続ける。
    - 追尾弾：両手を左右に上げ、指揮するように交互に振る。
    - 矢の雨：弓を空に向けて引き、何度も射る。
    - 弾幕：構えたまま、撃つたびに反動を受ける。
    - 砲撃：足を開いて踏ん張り、大きな反動を受ける。
    - 障壁：腕を交差してから、手のひらを外へ開く。
    - 鎖引き：投げてから全身で引き戻す。
    - 刈り取り：刃を低く後ろに構え、低く一回転して薙ぐ。
    - 残像：低く走りながら左右に揺れる。
    - 突撃：頭を下げ、肩から走り込む。
    - ブレス：頭をのけぞらせて吸い込み、前に吐き出す。
  - 刃の大技には三日月、爆発の大技には衝撃波の輪、障壁には半球の演出を、キャラクターの色で足しました。
- パリィやガードの動きは、技や大技の途中にも割り込みます。終わると、技や大技の動きの続きに戻ります。

## 4. 衛兵の武器の持ち替え（ご要望）
- 王国衛兵は、これまで電気銃（テーザー）だけを持ち、敵が目の前にいても、届かない遠くにいても撃っていました。
- 剣と盾、弓、拳銃（Superb Warfareのグロック17。無いときは電気銃）を持ち、0.5秒かけて状況に合わせて持ち替えます。
  - 敵が4ブロック以内（上下の差が少ないとき）：剣と盾。王国の兵のガードとパリィも使います。
  - 敵が見えていて15ブロック以内：拳銃。7〜14ブロックの距離を保ちます。
  - それより遠い、見えない、高く飛んでいる：弓。1秒引いて、矢の落ちる分を見込んで射ます。8〜28ブロックの距離を保ちます。
  - 敵がいないとき：剣と盾。
  - 戦争の突撃命令が出ているときは、何を持っていても近づきます。
- 村の衛兵（Guard Villagers）や武装した村人が銃を持っている場合：
  - 敵が3.5ブロック以内に来ると銃をしまい、剣（盾持ちの敵には斧）に持ち替えます。
  - 敵が6ブロック離れると、銃を出し直します。
  - 弓やクロスボウへの持ち替えは、これまでどおり村の仕組みが行います。
