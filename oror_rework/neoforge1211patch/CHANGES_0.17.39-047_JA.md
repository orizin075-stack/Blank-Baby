# OROR Nightfall 0.17.39-047-preview（046を土台）

046の続きです。

## 1. 村人王・将軍・近衛兵などの見た目を作り直しました
- 王族8種類（村人王・将軍・近衛兵・王族親衛隊・王国衛兵・王国魔法師団・上級魔導士・賢者）に、それぞれ専用の服を描きました。
  - これまでは普通の村人の体に、金ブロックやダイヤブロックの模様の箱をかぶせていただけでした。
  - 村人王: 赤い王衣、白い毛皮の肩掛け、金の鎖、白いひげ、宝石の付いた王冠、王家の紋章入りのマント
  - 将軍: 鋼の鎧と金の縁取り、紺の陣羽織に金の獅子、赤い飾り帯、赤い兜飾り、肩当て、赤いマント
  - 近衛兵: 白銀の鎧、白い陣羽織に青い十字、青い兜飾り、肩当て、青いマント
  - 一度作った見た目が「ちょっと気持ち悪い」とのことだったので作り直しました。白目をやめて落ち着いた目にし、肌や服の色むらを減らしています。
- 村人の体に、別々に動く腕を付けました。剣を振る、銃や弓を構える、魔導士が両手を上げて詠唱する、といった動きをします。
- 王は少し大きく（1.12倍）、将軍・親衛隊・近衛兵も少し大きく描きます。

## 2. 村人と行商人が腕で武器を振るように
- 武器や道具（剣・斧・つるはし・弓・弩・三叉槍・銃など）を持った村人と行商人は、組んでいた腕をほどきます。
  - 持った腕で武器を振ります。腕の袖は本人の服の模様のまま、手は本人の肌の色です。
- 何も持っていないときや、売り物を見せているときは、これまでどおり腕を組みます。
- Minecraftは、腕を振る動きの時計をモンスターとプレイヤーにしか進めません。そのため村人・行商人・王族は、攻撃しても腕が動きませんでした。この3種類も腕を振る動きが進むようにしました。

## 3. モブのドロップを直しました
- これまでは、プレイヤーが倒したモブはすべて、ランクに応じてエメラルド・ダイヤ・ネザライトの欠片・ネザライトインゴットを確定で落としていました（ランク6のゾンビならエメラルド48個・ダイヤ4個・欠片3個・インゴット2個）。動物や村人も同じでした。
- これからは次のとおりです。
  - 上乗せのドロップがあるのは敵対モブだけで、ランク2以上のときだけです。
  - 中心は「そのモブ自身のドロップの追加」です。ランクが高いスケルトンなら骨や矢が多めに出ます。
  - エメラルドは数個です。
  - ダイヤ・ネザライトの欠片・星のかけらは、強いモブからたまに出るだけです。

## 4. 動物や手のないモブが弓を撃たないように
- 賢いモブの戦闘AIは、どのモブにも弓・剣・防具を持たせていました。そのため、牛やクモが何もないところから矢を撃っていました。
- 武器を持てるモブだけが武器を使うようにしました。人・イリジャー・スケルトン・ゾンビ・ピグリン・ウィッチ・王族、それに他MODの人型の敵です。
- 動物などの手のないモブは、武器や防具を持たされなくなります。すでに持たされていたものは外します。
- 代わりの攻撃手段として「飛びかかり」を追加しました。3〜10ブロック離れた敵へ、2〜3秒おきに跳びかかります。

## 5. 宝物庫と禁庫（「王殺し」の武具、SBWの最強装備）
- 禁庫は、危険すぎる武具をしまっておく場所です。最初の2つの台座のチェスト「王家の禁庫・禁断の武具」に入れます。
- 王殺しの武具は7種類あります。
  - 剣「界断」・弓「天穿」・斧「断罪」・弩「堕星」・三叉槍「海嘯」
  - SBWの対物銃「穿界」（NTW-20）・砲「終焉」（セカンダリー・カタクリズム）
  - 同梱セーブでは、2つの台座に6種類ずつ入っています。斧は確率で外れ、入っていません。
  - 村人王の結界を、一撃で10秒間砕きます。砕けている間は、どの攻撃もそのまま王に通ります。
  - ほかに結界を割る方法は、結界の強さの2倍を1撃で与えることだけです。
- 危険なのは使う側も同じです。
  - 手に持つと、ウィザーと空腹にかかります。
  - 王に一撃を加えるたびに、持ち主も血を流します。
- 同じ台座に入るもの: ORORのレジェンド遺物・遺物の武器、ネザライト防具一式（最強エンチャント）、不死のトーテム、エンチャントされた金のリンゴ、SBWの危険な兵器（スーパースターシューター・トラケリウム・ビースト・ミニガン・ジャベリンとミサイル・AA-12）
- 禁庫のほかの台座: SBWの無限弾薬箱・C4・クレイモア・手榴弾・アナイアレイターの設計図・爆撃ドローン（バイラクタルTB2など）、ドラゴンスチール、伝説のインクなど
- 宝物庫: SBWの狙撃銃・機関銃など（AWM・M98B・MK14・QBZ-191・ベクター・SVD・RPK・M60など）、弾薬箱、防弾ベスト・ヘルメット、暗視ゴーグル、砲台の設計図、伝説の素材パックを加えました。
- 宝物庫のチェストは8個から12個に、禁庫の追加チェストは6個から10個に増やしました。

## 9. 戦車・航空機・ヘリ
- **原因を調べられるように**: 乗り物が傷んだとき、そのときの状況をログに出すようにしました（爆発・飛び道具・速度・壁に当たっていたか・地面からの高さ）。乗員を失ったときと落下したときも出します。
- **A-10が壊れていた原因**: 山の斜面への衝突でした。
  - 100人戦の場所も試験場も山の中で、巡航高度が周りの山より低く、旋回して斜面にぶつかっていました（衝突ダメージで機体が壊れ、乗員は墜落死）。
  - 巡航高度を、周囲16方向・175ブロック先までと進行方向220ブロック先までの一番高い地面より40ブロック上にしました。
  - 一度見た高い地面は30秒間覚えておきます。
  - 前方と左右25°の地形を見張ります。
  - 滑走路がない場所からの発進も、地面から30ブロック上にしました。
  - 100人戦では、A-10が最後まで飛び続けました（CI 2回とも、山の上空を巡回）。
- **戦車**: 
  - 前方の線上に地面や壁があるときは撃たないようにしました（自分の足元に砲弾を撃ち込まないため）。
  - 後ろの目標へは、後退しながら回らずに、前進しながら大回りするようにしました。試験場では、後退で塀を越えて斜面を滑り落ちていました。
  - 車体の「前」が向きと逆の車両でも、走らせながら学習して正しい向きで操縦します。
- **ヘリ（AH-6・Mi-28）**: 
  - SBWのヘリは、兵士が乗っていると上昇・旋回の入力に反応しませんでした（CIで3秒間上昇を入れても0ブロック）。
  - そのため、反応しないヘリは「補助操縦」で飛ばします。上昇・下降・向き・移動を直接動かし、敵の35ブロック手前・地面から22ブロック上に位置取ります。敵がいなければヘリポートに戻って降ります。
  - ヘリポートのヘリは乗員つき（操縦士と射手）になりました。
- 試験場は、山の谷間を避けて、周りの8か所から一番平らな乾いた土地を選ぶようにしました。

**CIでの結果（そのまま書きます）**
- A-10:
  - 試験飛行では、3分間一度も壊れずに飛び続けました（約1万5千ブロック、乗員も無事）。
  - 100人戦でも、最後まで飛び続けました。
  - ただし、今回の試験時間の中では急降下攻撃をしていません。高度を上げた分、攻撃の条件を満たしにくくなっています。
- ヘリ:
  - 試験場のAH-6は補助操縦で離陸し、移動して、ヘリポートに戻って降りました。壊れていません。
  - CIの城では、ヘリポートのヘリが高さ78前後で止まり、それ以上上がれませんでした。上に地形が残っている場所があるようで、原因はまだ調べきれていません。
- 戦車:
  - 目標（60ブロック先）には近づけませんでした（**未解決**）。
  - 走り出しの最初に、目標と逆の方へ大きく曲がってしまいます。そのまま試験場の外の斜面へ下りていきました。
  - 曲がる向きの学習がうまく働いていない可能性があり、引き続き調べます。
  - 試験場が山の中の谷間になっていたので、次回のCIからは平らな場所を選ぶようにしました。

## 10. 100人戦の重さ
- CIのサーバーでJavaのプロファイラ（JFR）を使い、100人戦中にどこで時間を使っているかを測りました。
  - 経路探索（モブの道探し）: 約2割
  - 王族の戦闘処理: 約1.5割（中身の多くは経路探索）
  - 他MOD（Alex's Cavesの磁力処理）: 約1割
  - 今回加えた航空機の地形チェック: 約8%
- 次のように軽くしました。
  - 経路探索: 同じ場所へ向かっている途中なら、1秒以内は道を探し直さないようにしました。遠い目的地ほど、多少動いても探し直しません。
  - 地形チェック: 2ティックに1回にし、読み込み済みのチャンクを直接読むようにしました。
  - 王国側の兵士が多く、試験の条件も回ごとに違うため、数字はまだ揺れています。最後のCIでは、180秒戦って1ティック平均128ミリ秒でした（目安は50ミリ秒）。
  - **目安の50ミリ秒には届いていません。** なお、このCIでは直前の城の試験で読み込んだ兵士・住民・車両（王族157人など）が残っていて、046のときより重い条件です。
- 城の試験のあと、使ったチャンクを1度に開放すると、サーバーの実体の後片付けで例外が起きて落ちたことがありました（CI 1回）。少しずつ開放するようにし、その後は起きていません。
