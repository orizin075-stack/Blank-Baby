# OROR Nightfall 0.17.39-058-preview（057の続き）

057の続きです。057の変更点（41体984技、メルスの城）と、それ以前の変更点はそのまま入っています。

## 1. 神討伐報酬164品を、設計書V9のとおりに入れ直しました（ご要望：「神討伐報酬164品・全説明書き直し V9」）

設計書の本文は `oror_rework/design/oror_164_relics_v9.txt` に置いてあります。
ツール（`tools/v9/`）がこれを読み取ってデータを作るので、手で書き写した箇所はありません。

### V8の現行値について（大事な点）
- 設計書が前提にしている「V8 JAR」は、このリポジトリにありません。こちらで作ってきたjarでは、炬珀の刀がまだ設定威力37・待機40tickのままでした。
- そこで、設計書に書かれたV8の数値と処理の文章から、V8のデータを組み立て直しました。
  - **設定威力と待機時間（CD）**：164品すべて、設計書の値にしました（例：蒼白断界刀・虚 316.67／110tick、超越神器 479.75／345tick）。攻撃属性は設計書の計算値と一致します（963、1936）。
  - **右クリック権能・命中処理**：設計書の「前方28m/幅3m・基準技威力×1.8・行動停止3秒…」という文章を、1項目ずつ命令に戻しました（`tools/v9/prose.py`）。既存の命令の位置にある細かい設定（跳躍距離、吹き飛ばしの強さ、確率の外れ側、エフェクト）は、既存のまま引き継いでいます。
  - **神罰（L125）**
    - 武器：命中ごとに抽選し、設計書の状態異常をLv125で与えます（例：炬珀は18%で移動速度低下1.6秒）。神罰刻印（5秒・被ダメ×2.15）も付きます。
    - 触媒：前方14ブロック・95度の敵へ与えます。
    - 装飾品：前方10ブロックへ与えます。
    - 超越神器：通常命中の30〜40%で与えます。
  - **報酬エンチャント**：神討伐武器と超越神器の82品が、ドロップした時に設計書の定義どおり付与されます（耐久力125・修繕1・ダメージ増加125・ドロップ増加12 など）。付与は一度だけで、後から付けたものは上書きしません。
  - **超越神器の3段階**：使うたびに 第1段階 → 第2段階 → 第3段階 と切り替わります（一回の演出で三段続けるものではありません）。各段階で、設計書のV7の効果・粒子数（26/34/58個）・専用の発動音が出ます。第3段階では、V8の追加分も出ます。
    - 半径14ブロック・最大14体へのL125神罰
    - 190tick・3.1倍の追撃刻印
    - 基準威力×1.25の追加攻撃
- V8 JARをお持ちなら、アップロードしていただければ、実データと照らし合わせます。

### L125の扱い（設計書の安全な挙動どおり）
- サーバーが神罰ごとに効果時間を管理します。時間が来たら、他の何かが延ばしていても外します。
- 同じ敵に同じ神罰は、切れてから2秒の猶予が過ぎるまで再付与しません。

### 神討伐武器の独立特殊技 123件（設計書V9の「特殊技Ⅰ・Ⅱ・武器専用必殺技」）
- **操作**：既存のコンボ・右クリック権能とは別に、専用キーで出します。神討伐武器を手に持っているときだけ効きます。
  - 特殊技Ⅰ＝**G**、特殊技Ⅱ＝**H**、必殺技＝**J**
  - キーは「操作設定 → OROR 神器」で変えられます。パックの既存キー（F・X・C・V・Z・R など）とは重なりません。
- **ゲージ**：ホットバーの右に3つの技の名前と再使用の残りが出ます。
- **流れ**：サーバーがすべて判定します。キーを押すと次の順に進みます。
  1. 武器を持っているか・再使用時間・ほかの技の準備中でないかを確かめる
  2. 構え（Ⅰ：構え8〜14tick＋狙い10〜20tick、Ⅱ：構築12〜24tick、必殺：大きな予兆20〜45tick）
  3. その時点の視線の向きへ解放（必殺技は解放後も20〜50tick形成が続きます）
- 構えている間は少し遅くなり、足元に技の範囲（直線・扇・円・狙う地点）が予告として描かれ、武器の先に光が集まります。必殺技は名前が頭上に出て、足元に大きな陣が出ます。
- 準備中に武器をしまう、倒れる、いなくなる、のどれかで技は途切れます。途切れた技は再使用時間を使いません。
- **ダメージ**：基準ダメージ（65,000〜1,500,000）を相手の防御計算へ入れます（固定の保証値ではありません）。再使用時間（9〜130秒）も設計書どおりです。
- **技ごとの中身**：設計書の説明文を、1技ずつ動作に組みました（`tools/v9/techniques.py`）。
  - 例：「断装・水鏡」は、受け流しの窓（成功で次の一撃が1.6倍）、前方16mの防御崩し斬撃（防具30%低下）、剣理印2層。
  - 例：「影縫い・無音」は、予測地点の背後へ回って横薙ぎ、6tick後に折返しの居合。印を消費して追加の斬撃。
  - 例：「とまれ」は、正面の敵を止めます。ボスには完全拘束ではなく減速と攻撃速度低下を与え、連続しては止めません。
  - ほかに、重力反転（落下ダメージは低速落下で抑えます）、九地点の落雷（屋根の下には落ちません）、色鬼（4色の陣のうち指名された色以外へ星降り）、じゃんけん（出目を先に表示）、契約（同意画面。拒否なら何も起きません）、3秒巻き戻し（自分の体力と位置だけ）、攻撃の保存と反射（上限付き）などがあります。
  - 設置物（砲台・結晶塔・獣・魔法陣・玩具兵・補給拠点・機神の腕など）は、敵が近くにいると削れて壊れます。持ち主1人につき最大8機です。
  - 領域は最大12秒で消えます。
- **見た目**
  - 技ごとに3Dの光の図形を、サーバーが言った場所・時刻に描きます。図形は18種類です：刃の弧・飛ぶ斬撃・光線・地の輪・魔法陣・光柱・岩や結晶の棘・降る光・鎖・ドーム・文字・光球・閃光・翼・樹・時計・拳・矢。
  - 粒子は、057と同じく他MOD由来のものを神格ごとの系統で使います。
  - Epic Fight の振りのモーションが入っていれば、それも再生します。

### 神威触媒（41品）
- 既存の中距離権能に、設計書のV7の増幅と、V8の神罰（前方14ブロック・95度、L125）・装備者へのバフを重ねました。
- 行動停止の効かない強敵（ボスなど）には、防御・再生・攻撃速度の抑制を8秒かけます（V9）。
- 対象は最大12体です（V9の「8〜16体」）。
- 詠唱開始（手元の陣）→ 成立（敵へ伸びる線）→ 命中（閃光）→ 残留（敵に残る陣）の4段階を見せます。

### 神格装飾品（41品）の危機対応（V9。着けているだけで自動で発動します）
設計書が神格ごとに割り当てた5種です。

| 種類 | 発動条件 | 効果 | 待機 |
|---|---|---|---|
| 反撃（炬珀・天輝・メルリヌス・シンラ・ウロボロス） | HP35%以下、または最大HPの30%以上の大技を受けた時 | その攻撃を90%軽減、最大HP25%回復、攻撃者へ反撃と強化解除、4秒間は次の一撃が2倍 | 65秒 |
| 制限印（理覇・ノルティア ほか） | HP40%以下 | 3秒間75%軽減、35%回復、攻撃者へ4秒の制限印（攻撃半減・減速・発光） | 80秒 |
| 牽制（カオス・ベーリット ほか17神） | HP35%以下 | 3.5秒間80%軽減、45%回復、近くの敵を一度吹き飛ばして打つ | 75秒 |
| 補修（ヴァレリア・フェルディナント ほか） | HP35%以下 | 補修の蔓を4機置く、40%回復、6秒間80%軽減 | 90秒 |
| 救済（セイヴァー・バハムート ほか） | 本人または半径20ブロックの味方がHP30%以下 | その人を65%回復、5秒間85%軽減 | 90秒 |

- 同じ種類の加護どうしで待機を共有します。
- 救済は、すでに死んだ者を生き返らせはしません。

### 超越神器（41品）の第三段階の極致（V9）
第3段階で、125tickの演出が出ます。

- 0〜20tick：構え
- 21〜60tick：形成
- 61〜100tick：攻撃とフィニッシュ
- 101〜125tick：残光

神格ごとに次の5通りです。

| 種類 | 内容 |
|---|---|
| 精密 | 敵の特殊防御を一つ解除してから、基準1,600,000の狭い一撃。強敵には最大HPの5%（上限2,000,000）を追加 |
| 法則 | 半径18ブロック・最大12体に基準1,250,000。神格固有の条件を5秒（重力・停止・封印・運命の刻印・玩具化・呪詛。契約は同意した相手だけ）。強敵には4%（上限1,500,000）を追加 |
| 大攻撃 | 基準1,800,000。強敵には8%（上限3,000,000）を追加。残る領域は12秒以内に消え、同じ相手への2撃目には猶予があります |
| 自律兵装 | 基準1,450,000の砲撃に加えて、自律砲台を最大6機（手持ちと合わせて8機まで、20秒）。この極致は90秒に一度です |
| 救済 | 半径32ブロックの味方最大16人を80%回復し、6秒間85%軽減。敵への攻撃は基準600,000に抑えます |

## 2. そのほか
- **057の不具合の修正（サーバーが落ちることがありました）**：技を使うキャラクターが召喚物ごとチャンクの読み込み解除で去るとき、召喚物を消す処理がチャンクのエンティティ一覧をたどっている最中に走り、サーバーがクラッシュすることがありました（058の最初のCIのゲームテストで発生）。消す処理を、そのtickのあとに回しました。
- 遺物の権能・特殊技の一撃は、モブのガード（パリィ）では受けられないようにしました。技が盾を割った相手、封印した相手も、その間はガードできません。
- 右クリック権能と特殊技の一撃にも、神罰刻印などの刻印の倍率が乗るようにしました。
