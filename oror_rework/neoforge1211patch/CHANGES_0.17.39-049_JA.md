# OROR Nightfall 0.17.39-049-preview（048を土台）

048の続きです。

## 1. 爆発でブロックがきちんと壊れるようにしました（ご要望）
- 048では、王都の中では王国軍（兵士・車両・砲台）の爆発でブロックが壊れず、城の区画（内堀の内側）ではどの爆発でも壊れないようにしていました。
  - これをやめました。王都の中でも外でも、爆発で普通にブロックが壊れます。プレイヤーの爆発も同じです。
- 略奪者のバズーカ（Pillagers Gun）だけはブロックを壊さない設定だったので、壊す設定に変えました（config/pillagers_gun.json の bazookaBreakBlocks）。
  - 戦車・砲台（Superb Warfare）、TACZ、JEGの爆発は、もともとブロックを壊す設定です。
- 注意：
  - 王国の砲台・戦車・ヘリの外れ弾で、城や町の屋根がまた壊れることがあります。
  - 地上の車両と砲台は、狙いの線が地面や壁にかかると撃たないので、048より前ほどは壊れません。

## 2. 生成済みワールドの王都も、新しい作りに更新されます
- これまでは、修理や配置換えは新しく生成される王都と同梱セーブにしか入りませんでした。今の版から、前の版で生成された王都も更新されます。
- 仕組み：
  - これまで配布した王都の設計図（9版）と049の設計図を比べ、違うブロック約94万個に印を付けたデータ（update.bin、約0.3 MB）を同梱しました。
  - 王都のチャンクが読み込まれたとき、印のあるブロックだけを049のものに置き換えます（1ティックに最大4,000ブロック）。
  - 印のない場所（プレイヤーが建てた物や壊した所など）には触れません。
  - 049で生成されたチャンクは、もともと049の作りなので何も変わりません。
- 主に変わるもの：
  - 城の屋根（048でふさいだ吹き抜け）
  - 滑走路・ヘリポート・戦車格納庫の場所（城壁の内側）と補給設備
  - 噴水の縁（下の4）
  - 047・048で建て直した町の家
- 箱の中身：
  - 古い版で王国が置いたチェストや樽が別のブロックに置き換わるときは、先に中身を消します。王国の在庫が通りに散らばらないようにするためです。
  - プレイヤーが置いた箱が置き換わる場所にあれば、普通に壊したときと同じく中身が落ちます。
  - 新しく置かれた箱や補給設備には、049の中身が入ります。
- 車両：
  - 古い版の持ち場（城壁の外の旧滑走路・旧格納庫・旧ヘリポートなど）に残った王国の車両は、乗員ごと引き上げます。
  - 049の持ち場で車両がいない所には、新しく車両と乗員を出します。
  - プレイヤーが乗っている車両には手を付けません。
- 進み具合は `/oror citadel update` で見られます。王都を歩くと、読み込まれた所から順に更新されます。

## 3. A-10の自動着陸：着陸できなかった原因が見つかりました
- 着陸の進入中、「進入路の地面が高すぎないか」を毎ティック確かめています。この判定が、平らな地面そのものを障害物と数えていました。
  - 地面の高さ65に対し、障害物とみなす線が64.5でした。
  - このため進入を始めるとすぐ「進入路がふさがっている」と判断し、やり直しを繰り返していました。5回の試験で一度も着地できなかったのはこのためです。
- 滑走路の高さより2ブロック以内の地面は障害物にしないよう直しました。
- 帰り道も、滑走路の延長線上の遠い地点（進入開始点）にまず向かい、そこから滑走路にまっすぐ入るようにしました。

## 4. 王都の点検で見つかった壊れた所・置き忘れ
王都全体を自動で点検する道具（tools/citadel/audit.py）で、建物・城・城壁・道・軍の持ち場・兵士の立ち位置を調べ、見つかったものを直しました。
- 噴水と池に縁がありませんでした（872か所）。
  - 4本の大通りの真ん中の円い噴水、広場の水盤、畑の池、浴場などで、水を受ける縁がなく、ゲーム内では水が通りにあふれていました（設計元の045セーブからあったもの）。
  - 縁を水盤と同じ石で988ブロック足しました。
  - 水面の上に浮いていた噴水の頂部（8か所、232ブロック）の下は、同じ石の台座で埋めました。
  - 中庭の池の上に1つだけ浮いていた本棚などは取り除きました。
- 2本目の滑走路を南から東へ移しました。
  - 048で南の農地帯に置いた滑走路は、着陸の進入路に高さ33ブロックの建物（ダークオークの館）が立っていました。
  - 南の農地帯は粉ひき小屋や納屋が多く、進入路が空く場所がありませんでした。そこで、東の農地帯に南北向きの滑走路を作りました（北へ離陸し、南の畑の上から進入します）。
  - 滑走路を置くときは、進入路の下に建物がないか確かめ、進入路にかかる木は切るようにしました。
- A-10の充電設備と弾薬庫が翼の端にかかっていたので、機体の尾の9ブロック後ろへ移しました。
- 砲台の持ち場のうち、台の3ブロック上に浮いていたもの（門の道の十字砲火の位置）を、台の上に下ろしました。
- 衛兵の電気銃の充電設備を、城門の外の砦・見張り塔・町の詰所にも置きました（048では城門だけでした）。
- 城の中で、何にも付いていないブロック（門の上の飾り、屋上の角のランタンや瓦）を64個取り除きました。
- 点検の結果、問題がなかったもの：
  - 町の建物340軒、ベッド1,273台（住民1,083人）
  - 兵士・住民の立ち位置1,553か所すべて
  - 城の屋根、城壁、大通り、補給設備
