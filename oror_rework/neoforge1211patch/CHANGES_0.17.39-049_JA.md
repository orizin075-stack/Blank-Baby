# OROR Nightfall 0.17.39-049-preview（048を土台）

048の続きです。

## 1. 爆発でブロックがきちんと壊れるようにしました（ご要望）
- 048では、王都の中では王国軍（兵士・車両・砲台）の爆発でブロックが壊れず、城の区画（内堀の内側）ではどの爆発でも壊れないようにしていました。
  - これをやめました。王都の中でも外でも、爆発で普通にブロックが壊れます。プレイヤーの爆発も同じです。
- 略奪者のバズーカ（Pillagers Gun）だけはブロックを壊さない設定だったので、壊す設定に変えました（config/pillagers_gun.json の bazookaBreakBlocks）。
  - 戦車・砲台（Superb Warfare）、TACZ、JEGの爆発は、もともとブロックを壊す設定です。
- 注意：
  - 王国の砲台・戦車・ヘリの外れ弾で、城や町の屋根がまた壊れることがあります。
  - 地上の車両と砲台は、狙いの線が地面や壁にかかると撃ちません。

## 2. 壊れていた建物を直しました（ご指摘）
王都の自動生成（045）のままだった建物に、壁や屋根の抜け、空中に浮いた部品がありました。王都全体を調べて直しました。
- 牧場の納屋（8棟）：
  - 屋根の両端の三角の壁がなく、屋根の真ん中も抜けていて、中が空から丸見えでした。
  - 壊れた納屋を取り払い、町の家と同じ作りの厩舎を建て直しました（干し草・樽・寝台つき）。
  - 囲い・畑・動物はそのままです。
- 外の4つの砦の中の建物：
  - 屋根の両端が開いていたので、壁でふさぎました。
  - 屋根が壁から1段浮いていたので、壁を屋根の下まで伸ばしてつなげました。
- 地面や建物から浮いていた部品：
  - 外壁と城壁の控え壁が、地面から1ブロック浮いて建っていました。すき間を同じ石で埋めて地面に着けました（136か所）。
  - 壁や屋根から1〜2ブロック離れて浮いていた部品は、間を埋めてつなげました（40か所）。
  - 幹のない木の葉の塊、空中の土の塊、城の南の中庭の上に浮いていた屋根の棟だけの梁などは取り除きました（111か所）。
- 屋根の下で三角に開いていた妻壁は、壁でふさぎました。門の通路や、側面の開いた見張り台はそのままです。
- 点検ツールに「地面とつながっていない塊」の確認を加え、修理後の王都で残りがないことを確かめています（城の中の照明などの小物は除く）。

## 3. 戦車の格納庫を大通り沿いに移しました（ご指摘）
- 048の格納庫は扉の前がすぐ畑で、戦車が作物の上を走って出て行く作りでした。
- 4棟とも、城から延びる4本の大通りの脇（城から約405ブロック）に移しました。
  - 扉は通りに向いています。
  - 扉の前から通りまでをコンクリートで舗装したので、戦車は畑を通らずに通りへ出ます。
- 生成済みのワールドでは、古い格納庫の場所は畑に戻ります。古い格納庫の戦車は引き上げられ、新しい格納庫に戦車が出ます（下の4）。

## 4. 生成済みワールドの王都も、新しい作りに更新されます
- これまでは、修理や配置換えは新しく生成される王都と同梱セーブにしか入りませんでした。今の版から、前の版で生成された王都も更新されます。
- 仕組み：
  - これまで配布した王都の設計図（9版）と049の設計図を比べ、違うブロックだけに印を付けたデータ（update.bin）を同梱しました。
  - 王都のチャンクが読み込まれたとき、印のあるブロックだけを049のものに置き換えます（1ティックに最大4,000ブロック）。
  - 印のない場所（プレイヤーが建てた物や壊した所など）には触れません。049で生成されたチャンクは何も変わりません。
- 箱の中身：
  - 古い版で王国が置いたチェストや樽が別のブロックに置き換わるときは、先に中身を消します（王国の在庫が通りに散らばらないように）。
  - プレイヤーが置いた箱が置き換わる場所にあれば、普通に壊したときと同じく中身が落ちます。
- 車両：
  - 古い版の持ち場（城壁の外の旧滑走路、旧格納庫など）に残った王国の車両は、乗員ごと引き上げます。
  - 049の持ち場で車両がいない所には、車両と乗員を出します。
  - プレイヤーが乗っている車両には手を付けません。
- 進み具合は `/oror citadel update` で見られます。王都を歩くと、読み込まれた所から順に更新されます。

## 5. 王都の点検で見つかった、そのほかの壊れた所・置き忘れ
- 噴水と池に、水を受ける縁がありませんでした（872か所）。
  - 4本の大通りの真ん中の円い噴水、広場の水盤、畑の池、浴場などです。ゲーム内では水が通りにあふれていました。
  - 縁を水盤と同じ石で足しました。
  - 水面の上に浮いていた噴水の頂部の下は、同じ石の台座で埋めました。
- 2本目の滑走路を南から東へ移しました。
  - 南の農地帯は粉ひき小屋や納屋が多く、着陸の進入路が空く場所がありませんでした（048では進入路に高さ33ブロックの建物）。
  - 東の農地帯に南北向きの滑走路を作りました。
  - 滑走路を置くときは、進入路の下に建物がないかを確かめるようにしました。
- A-10の充電設備と弾薬庫が翼の端にかかっていたので、機体の後ろへ移しました。
- 砲台の持ち場のうち、台の3ブロック上に浮いていたもの（門の道の十字砲火の位置）を、台の上に下ろしました。
- 衛兵の電気銃の充電設備を、外の砦・見張り塔・町の詰所にも置きました（048では城門だけでした）。

## 6. A-10の自動着陸（まだ完成していません）
- 着陸できなかった大きな原因を1つ直しました。
  - 進入中に「進入路の地面が高すぎないか」を確かめる判定が、平らな地面そのものを障害物と数えていました。
  - そのため、進入を始めるとすぐにやり直していました。
- 帰り道も見直しました。
  - 滑走路の延長線上の遠い地点（進入開始点）に向かってから、滑走路にまっすぐ入るようにしました。
  - 旋回中は周りの地形の高さを見て飛び、延長線に乗ってからは、すぐ横の丘にも近づかないようにしました。
- CIの結果：
  - 墜落せずに帰還し、進入開始点まで来られるようになりました。
  - ただし旋回の輪が大きく（直径約400ブロック）、滑走路の線に乗れないまま回り続けました。
  - 機首を直接回して旋回を小さくする方法も試しましたが、その回は滑走路の手前で地面に落ちたので外しました。
- 着陸の完成は次の版の課題です。今は、電池が10%を切るか弾がなくなるまで戦い、その後は滑走路の上空を回ります。
