# OROR Nightfall 0.17.39-050-preview（049を土台）

049の続きです。ご指摘の3点を直しました。

## 1. 滑走路に木の葉が突っ込んでいたのを直しました（ご指摘）
- 滑走路のまわり12ブロック、ヘリポート・格納庫・対空砲台のまわり6ブロック以内にかかる木と茂みを、幹ごと丸ごと切りました（1,561ブロック）。
  - 葉だけを切ると幹が残ったり、木の上半分が浮いたりするので、かかっている木は1本まるごと取り除いています。

## 2. 砲台を増やし、対空防御を固めました（ご要望）
- 砲台は120基から168基になりました。うち対空機関砲（CIWS、HPJ-11）は72基です。
  - 外壁の砲台：3つに1つから、2つに1つに増やしました。半分はCIWSです。
  - 新しい対空陣地（コンクリートの台、充電設備・弾薬庫つき）を16か所に作りました。
    - 2本の滑走路の両端（4か所）
    - 4つのヘリポート、4つの格納庫の脇（8か所）
    - 町の内側の4つの門の近く（4か所）
- 砲台の狙い方も直しました。
  - これまで地上の車両と砲台は、上下24ブロックの範囲でしか敵を探していませんでした。そのため、高く飛ぶ敵は撃っていませんでした。
  - 砲台は上下64ブロック、CIWSは上下128ブロック・半径128ブロックで敵を探します。
  - CIWSは、空を飛んでいる敵を地上の敵より先に狙います。
- CIの試験：
  - 夜空にファントム4体を出し、CIWS1基で迎え撃たせました。
  - 4体とも4.2秒で撃墜しました（1体目は0.8秒）。

## 3. A-10が自分で着陸できるようになりました（ご要望：操縦技術）
CIの記録を0.5秒ごとに全部残すようにして、着陸できなかった原因を1つずつ直しました。
- 旋回：
  - 主翼を傾けるだけでは旋回の輪が直径約400ブロックもあり、滑走路の延長線に乗れませんでした。
  - 地面から25ブロック以上離れているときは、機首の向きも直接少しずつ回して、小さく旋回します。
- 傾きすぎの防止：
  - 帰り道の旋回で、地面からの高さを常に「99」として扱っていたため、低空でも深く傾けていました。
  - 実際の高さを使い、低いところでは浅くしか傾けません。50°を超えたら水平に戻します。
  - 049の試験で、やり直しの旋回中に地面近くで90°以上傾いて墜落したのは、これが原因でした。
- 速度：
  - 帰りの降下で速度が出すぎていました（目標の約2倍）。
  - 速すぎる間は機首を下げずに減速を優先し、滑走路の線に乗った後は着陸速度近くまで落とします。
- 進入：
  - 接地点を高いまま通り過ぎたら、すぐにやり直します。
  - 狙う接地点は、滑走路の始まりから40ブロック内側にしました。
- CIの結果：
  - 戦闘のあと電池が減ると基地へ帰りました。1回目は高すぎてやり直し、2回目で滑走路の線に乗って接地しました。
  - その後は滑走路上で止まり、自分の駐機場まで地上走行して駐機しました。
  - 駐機場で弾148発の補給と充電を受けました。機体の損傷はありません。
