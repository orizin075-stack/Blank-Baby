# OROR Nightfall 0.17.39-056-preview（055の続き）

055の続きです。055の変更点は、そのまま入っています（overrides/CHANGES_0.17.39-055_JA.md）。

## 1. アザゼルを作り直しました（ご要望）
### これまで
- アザゼル［神に叛きし者］は、普通のエヴォーカーに名前とネザライトの剣を持たせただけでした。見た目はエヴォーカーのままで、技もエヴォーカーの魔法（牙・ヴェックス）だけでした。

### 姿
エノク書とレビ記のアザゼルを元にしました。天から降りて人に剣・盾・胸当ての鍛え方を教えた見張りの天使の長で、そのために手足を縛られ、荒野ドゥダエルの闇に投げ込まれ、ごつごつした岩を積まれた者です。「贖罪の山羊」が送られる相手でもあります。このMODでは略奪者たちの主なので、**略奪者が堕天使になった姿**にしました。
- 顔：略奪者の灰色の長い顔と大きな鼻、しかめた一本の太い眉、紫に燃える目。頬には熾火のひび（堕ちたときの焼け跡）。
- 角と冠：贖罪の山羊の巻き角。鍛えた黒鉄の棘の冠に、紫の宝石。
- 光輪：黒い鉄の、半分に折れた光輪。折れた端だけが、冷めかけた炉のように光ります。
- 翼：焦げた羽根の翼が4枚。縁が熾火のように光ります。下の2枚は裂けています。
- 衣と鎧：黒いエヴォーカーの衣（青銅の縁取りと紫の文字）。その上に、彼が人に教えた青銅の胸当てと肩当て、籠手、鍛冶の革帯。胸には青銅の山羊の頭蓋の印。
- 鎖：ラファエルに縛られた枷を、両手首と両足首に。引きちぎった鎖が垂れています。
- 周りには、ドゥダエルの岩が背中で回り、火の粉が舞います。
- 武器：叛神剣（王殺し）。黒い鍛鉄の、刃こぼれのようなぎざぎざの刃に、溶けた火の筋とひびが光ります。鍔は紫の目を巻く二本の巻き角、柄頭は山羊の頭蓋です。左の手のひらの上には、紫の炎が浮かびます。
- 背丈は普通の略奪者の1.45倍（化身は1.3倍）です。

### 技（10種、それぞれ専用の動き）
エヴォーカーの魔法（牙・ヴェックス）は、これまでどおり使います。それに加えて、次の10の技を使います。

| 技 | 中身 | 動き |
|---|---|---|
| 叛神剣・三連 | 前の扇形を3回斬る（1回14ダメージ） | 右から左、左から右と、腰をひねって斬り返す |
| 鍛冶神の剣雨 | 20ブロック以内の敵6人まで、自分が鍛えた剣が空から降る（16ダメージ、鈍化） | 左手を天に掲げて剣を呼び、振り下ろす |
| 牙の大陣 | 自分の周りに4重の輪で牙を出す（内から外へ順に、すき間なし） | 両手で剣を掲げ、片膝をついて地に突き立てる |
| 蝕の羽ばたき | 前方の敵を盲目・暗闇にし、吹き飛ばす（8ダメージ） | 腕を翼とともに後ろへ広げ、前へ振る |
| 贖罪の山羊 | 敵ひとりを12秒間「山羊」にする。アザゼルが受けた傷の6割が、その者に移る | 左手で指さし、拳を胸に引く |
| 荒野の岩 | ドゥダエルの岩が、敵の周りに3回降る（18ダメージ、足止め） | 両腕を掲げ、叩き下ろす |
| 禁断の知識 | 「剣の作り方を教えたのは我だ」：敵の手の武器をもぎ取り、遠くへ投げ捨てる | 左手を伸ばしてつかみ、引き戻す |
| 堕天の急降下 | 翼で跳び上がり、敵の上へ落ちる（周り4.5ブロック、22ダメージ） | しゃがむ、剣を振りかぶって宙へ、叩きつける |
| 解かれた鎖 | 12ブロック以内の敵を鎖で引き寄せて縛り、少しして鎖が砕ける（14ダメージ） | 縛られたように腕を交差し、振りほどき、鎖を引く |
| 叛逆の号令 | 周りの略奪者を強くし（力・速さ・耐性）、ヴェックスを3匹呼ぶ | 剣を天に突き上げ、拳を上げて吠える |

- 村人王（とその配下）には、これまでどおり「王殺し」の力が働きます（技の一撃でも、王の結界をすぐに割ります）。
- 相手の武器を奪う技は、村人王の剣は奪いません。

## 2. 反逆証明書（ご要望）
略奪者たちの信用を得るための証文です。村人を利用して作り、行商人に見せると、略奪者の都への地図がもらえます。
- **村人の血判**：紙を手に持ってしゃがみ、村人に使います。村人に指を切らせ、血の印を押させます。
  - その村人は少し傷つき、あなたを信用しなくなります（評判が下がります）。
  - 1人の村人からは1回だけです。子供からは取れません。
- **反逆証明書のレシピ**（形は自由）：村人の血判3つ、紙、イカスミ、エメラルド。
- **持っているあいだ**：略奪者・魔女・ピグリン・エンダーマンが、あなたを仲間と見なして襲いません（村人王の敵になったときと同じです）。アザゼルも襲ってきません。
- **略奪者に見せる**（手に持って話しかける）：信用され、取引できるようになります。
- **行商人に見せる**（手に持って話しかける）：行商人が、いちばん近い**略奪者の都（アザゼルの城）か要塞への地図**をくれます。地図には赤い×の印が付きます。行商人1人につき1回です。

## 3. 検証結果
CI（NeoForge 1.21.1 の専用サーバー、053 パックのMOD入り）で、王の物語を最初から最後まで自動で通しました（056のビルド）。
- 王の物語の全項目：合格（055までの項目も、すべて合格のままです）。
- アザゼル：
  - 背丈は普通の略奪者の1.45倍になりました。
  - 10の技すべてが、鉄の剣を持った試し打ちの的に当たりました。
    - 当たった回数：叛神剣・三連 3、鍛冶神の剣雨 3、牙の大陣 2、蝕の羽ばたき 3、荒野の岩 48（岩ひとつごとに数えています）、堕天の急降下 2、解かれた鎖 5（5回とも縛りました）、叛逆の号令 1。
    - 贖罪の山羊：「山羊」にした的へ、アザゼルの傷が移りました。
    - 禁断の知識：的の手から剣がなくなりました。
- 反逆証明書：
  - 村人3人から血判を取れました。同じ村人からは2回目を取れません。
  - レシピで証明書を作れました。
  - 持つ前は略奪者の仲間と見なされず、持つと仲間と見なされました。
  - 行商人に見せると、地図をもらえました。地図の×印は、いちばん近い略奪者の都です。都を探す時間は0.27秒でした。
- 武器ごとの技70種：69種が試し打ちの的に当たりました。外れたのは崩壊王の「断片斬り」1種で、055の最終ビルドでは当たっていました（合格の基準は満たしています）。
- 大技42種：すべて当たりました。
- ORORの自動試験（GameTest）：116件中110件合格。不合格の6件は、055までと同じ顔ぶれです。055で不合格だった「熟練の村人がネザライト装備のプレイヤーに勝つ」は、今回は通りました（通る回と通らない回がある試験です）。
