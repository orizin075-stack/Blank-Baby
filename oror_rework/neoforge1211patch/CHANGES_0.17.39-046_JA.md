# OROR Nightfall 0.17.39-046-preview（045を土台）

045の続きです。

## 0. 王国の場所と「王都」バイオーム
- 王国（グランドシタデル）は、ワールドのスポーン地点から**半径1,000ブロック以内**に1つだけ建ちます。
  - 中心はスポーンから820〜960ブロック。スポーン地点が城壁の外になる向きを選びます。
  - 場所選びは新しいワールドを作るときに1回だけ行います（CIのサーバーで約11秒）。
  - 周囲の候補の中から、いちばん乾いて平らな土地を選びます。
  - 場所はワールドに保存され、毎回同じです。
  - 既存のワールドでは、まだ生成されていない土地を選びます（作りかけの城になりません）。
  - ゲームが決めたスポーンが王国の中や遠くになった場合は、スポーンを王国の門の前に移します。
- 王国の全チャンクは新しいバイオーム**「王都」**（oror_supreme_bosses:royal_capital）です。
  - 敵対モブが自然に湧きません（家畜は湧きます）。
  - 草と空の色も王都専用です。F3画面のバイオーム欄には oror_supreme_bosses:royal_capital と出ます。
- 同梱セーブの王国も、全体が「王都」バイオームです。
- 探し方は `/oror citadel locate` です。

## 8. 戦車・航空機の自律操縦、100人戦
- **航空機**: 降下攻撃の機首引き起こしが遅れて地面に激突することがありました（CIの試験で確認）。次のように直しました。
  - 降下を始めるのは目標より40ブロック以上高いときだけです。
  - 降下角は最大28°です。
  - 沈む速さに応じた余裕を持って機首を上げ、再び上昇に移るまで全開で引き起こします。
  - 地形の見張りは、上下の動きも含めた0.5〜2秒先の位置で判断します。
  - 飛行中は常に全開にし、速度が落ちたら（地面から20ブロック以上あれば）機首を下げて速度を取り戻します。
  - 滑走路の確認で、まだ読み込まれていない先のチャンクを「障害物あり」と見なさないようにしました。
- **戦車・航空機の目標**: 乗員の兵士は自分の追跡距離の外の敵を見失います。そのため、戦車が「敵へ向かう」と「持ち場へ戻る」を毎秒繰り返し、ほとんど前に進まないことがありました（CIの試験で30秒に8.6ブロック）。乗り物が追っている敵を自分で覚えるようにしました。対象は、生きていて地上車両は96ブロック以内（航空機は220ブロック）、20秒以内に確認できた敵です。
- 100人戦: `/oror war start [人数] [test]`。

**CIでの結果（そのまま書きます）**

  - A-10は飛び立って約285ブロック進んだところで壊れました。前回のCIとまったく同じ壊れ方で、今回の修正では直っていません。
- ヘリ（AH-6・Mi-28）は自律飛行に対応していないので、ヘリポートに駐機しているだけです。
