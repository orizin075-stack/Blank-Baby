# OROR Nightfall 0.17.39-053-preview（052 gatefix8 を土台）

052の続きです。いただいた 052 gatefix8（TUKUYO 連携、地下隔壁のボタン、樽、必須MODの表示、検証用の仕組みなど）を土台にしたので、その修正はすべてそのまま入っています。

## 1. クラッシュ（ご報告）
### サーバーが止まる不具合を1つ見つけて直しました
- CIの2回目で、サーバーが止まりました。
  - 原因：世界が作られるときに建物（構造物）が置いた行商人が、その場で保存されます。そのとき、初めて取引の一覧が作られます。その中に「何も売らない取引」（空のアイテム）が1つありました。Minecraft は、書き出せない取引があると、サーバーごと止まります。
  - エラーの文面は「Saving entity NBT … Value must be within range [1;99]: 0; Item must not be minecraft:air」です。
  - この空の取引は、パックのほかのMODの取引から来ていると思われます（ORORの行商人の品揃えは、行商人が動き出してから足すもので、このときはまだ足していません）。
- 村人と行商人の取引から、書き出せない取引を取り除くようにしました（保存・表示・取引のとき）。
  - 対象は、何も売らない取引、1スタックに入りきらない数を売る取引、何も求めない取引です。
  - 取り除いた取引はログに残します（OROR-TRADE-DROPPED）。どのMODの取引かを探す手がかりになります。
  - プレイヤーに見せた場合も、同じ取引で接続が切れるはずだったので、それも防げます。
- 3回目のCIでは、同じ場所でサーバーが固まりました（クラッシュはせず、そのまま応答がなくなりました）。
  - 行商人の取引を、世界を作っている途中に作っていたことが原因と考えています。取引の中には、近くの建物への地図のように、世界を探して作るものがあります。
  - 世界に出る前の村人と行商人は、取引を作らないようにしました。取引は、世界に出てから最初に必要になったときに、サーバーの本来の処理の中で作ります。
  - この修正を入れた5回目のCIでも、固まらずに最後まで進みました（修正前の4回目も固まらなかったので、固まる条件そのものは毎回は起きません）。
  - サーバーが3分間何も記録しなくなったら、すべての処理の状態を記録し、10分で止めるようにしました（CIのみ）。次に固まったときは、どこで止まったかがわかります。
- いただいた「衛兵が魔法を使ったらクラッシュした」が、この不具合と同じものかは確かめられていません。ただ、戦いで周りのチャンクが新しく作られたときに起きた可能性はあります。

### 衛兵の魔法
- 王国の兵（衛兵・魔術師など）が使う呪文を、Iron's Spells 本体の戦闘用の呪文だけにしました。
  - これまでは、入っているすべての呪文から選んでいました。アドオンの呪文（地属性の追加MODなど）や、プレイヤーが手で使う前提の呪文も含まれていました。
  - 火・氷・雷・聖・エンダー・血・喚起・自然・異界の呪文から、攻撃・回復・守り・召喚に使うものを選んでいます。
- 王国の兵は「アローボレー」を使わないようにしました。1回で十数本の矢を出し、その矢が地面に残り続けます（100人の戦いで346本残っていて、重さの原因になっていました）。今は69種類です。
- CIで、これまでの呪文の一覧の全123種を、1つずつ王国の兵に実際に撃たせました（相手は動かないゾンビ、毎回実施）。
  - 詠唱が始まったのは117種でした。サーバーが止まったものと、兵が消えたものは、毎回0でした。
  - 「この呪文を撃つと落ちる」という形では、再現できませんでした。
- もう一段の守りとして、モブの処理でエラーが出たときは、サーバーを止めずに、そのモブだけを消すようにしました（NeoForge の設定 removeErroringEntities を有効にしました）。
  - 次に同じようなことが起きても、サーバーは止まらずにログに記録が残ります。その記録をいただければ、原因を特定できます。

## 2. ウィザースケルトンなどのモブの挙動がおかしい（ご報告）
052で入れた「全モブのガードとパリィ」が原因でした。
- モブ同士の戦い（ゴーレムとゾンビ、王国の兵とモブ、モブ同士の乱闘）でも、ガードが働いていました。
- パリィされると、Epic Fight の長いよろけで固まっていました。
- ガードのたびに Epic Fight のガードの動きを再生していたので、その場で立ち止まっていました。ガードが崩れると、2秒の「無力化」の動きでした。
- 弓を持つモブまで構えていました。

次のように直しました。
- モブがガードするのは、プレイヤーの攻撃だけにしました。
- パリィされたモブのよろけは、Epic Fight の短いよろけにしました。
- ガードの動きは火花と構え（ORORのモデルだけ）にしました。パリィとガード崩れは、Epic Fight の短い被弾の動きにしました。
- 弓とクロスボウを持つモブは、ガードしません。
- 盾のないモブのガードは、攻撃を無効にせず、半分にするだけにしました（ボスを除く）。
- よろけの間、毎ティック移動を止めていたのをやめました（ガードが崩れたときに一度だけ止めます）。

もう1つの原因は、ORORの「賢いモブ」（AdaptiveCombat）でした。
- 相手が8ブロックより遠いと、どのモブにも弓を持たせていました。
- そのため、ウィザースケルトンが剣をしまって弓で遠くから撃ったり、ピグリンブルートが8ブロック離れて立ち止まり矢を射ったりしていました（CIで両方を確認しました）。
- 生まれつき近接で戦うモンスター（ゾンビ、ハスク、ウィザースケルトン、ヴィンディケーター、ピグリンブルート、ゾンビピグリンなど）は、遠くの相手にも近接武器のまま近づくようにしました。
  - スケルトン、ピリジャー、ウィッチ、ドラウンドなど、もともと遠距離で戦うモブはこれまでどおりです。
  - ORORのキャラクター、王国の兵、村人も、これまでどおり状況で武器を持ち替えます。

CIで、10種類のモブ（ウィザースケルトン、スケルトン、ゾンビ、ハスク、ピグリンブルート、ヴィンディケーター、クモ、ブレイズ、ピリジャー、ゾンビピグリン）を、それぞれ動かないアイアンゴーレムと戦わせました。どのモブも近づいて攻撃しました（結果は「9. 検証結果」）。

### 銃を持つモブ（ご指摘）
このパックでは、ピリジャー（Pillagers Gun、Pillager Guns）、TACZ Bandits の盗賊、JEG のモブなどが銃を持っています。
- ORORのガード（「全モブのガードとパリィ」）は、弓とクロスボウを持つモブには構えさせていませんでしたが、銃は対象外にしていませんでした。そのため、銃を持つモブが撃っている途中で、剣と盾の構えをしていました。銃を持つモブも構えないようにしました。
- CIに、銃を持つモブの検査を加えました（/oror gunmobs test）。
  - 野外と同じ出し方で、Minecraft の人型の敵と、銃のMODのモブを12体ずつ出し、何を持っているかを数えます。
  - 銃を持っていた種類と、ゾンビ・スケルトン・ウィザースケルトン・ヴィンディケーターに一番多かった銃を持たせたものを、ゴーレム相手に戦わせます。開けた場所（24ブロック先）と、壁の向こう（14ブロック先、左右に回り道あり）の2通りです。
  - 結果は「9. 検証結果」に書きます。

## 3. 重すぎる（ご報告）
- CIで、王都の周り17×17チャンク（289チャンク、モブや乗り物など1,093体）を読み込みました。普段の状態の負荷を1分間測りました。
  - 最初の測定では、1ティックの平均が28ミリ秒でした（上限の目安は50ミリ秒）。そのうち約半分は Alex's Caves の磁石の探索でした。
  - Alex's Caves は、すべてのモブの周り5ブロックを、毎ティック2回（引き寄せる磁石と、はじく磁石）探します。近くに磁石が1つもなくても探します。100人の戦いでも、サーバーの3分の1を使っていました。
  - 053の最初の版で入れた節約の仕組みは、かえって重くなっていました（16ブロックの区画ごとに広く探していたため）。2ブロックの区画ごとに少しだけ広く探し、その答えを2秒間、区画の中のモブで使い回すように直しました。磁石が置かれれば、2秒以内に効き始めます。
  - 直したあと（2回目のCI）：
    - 王都：磁石の探索は、サーバーの時間の47%から7%になりました。1ティックの時間は、重いほうの5%が43ミリ秒から35ミリ秒に、最大が169ミリ秒から59ミリ秒になりました。平均は27ミリ秒でほぼ同じです（この回は読み込まれたモブが769体で、1回目の1,093体とは条件が違います）。
    - 衛兵1人あたりの時間は、半分以下になりました（0.080ミリ秒から0.035ミリ秒）。
    - 100人の戦い：磁石の探索は、サーバーの時間の27%から4%になりました。
  - 3〜5回目のCI（磁石の修正のあと）：王都の1ティックの時間は、平均15〜26ミリ秒、重いほうの5%で19〜35ミリ秒、最大47〜73ミリ秒でした（1回目は平均28、重いほうの5%で43、最大169）。
    - CIのサーバーは回ごとに速さがかなり違うので、数値は目安です。はっきり下がったのは、重いほうの5%と最大（カクつき）です。
- 今いちばん重いのは、Superb Warfare の戦車・砲台・対空砲です（王都で全体の約3割）。止まっていても毎ティック、物理と武器の計算をしています。Superb Warfare 側の処理なので、今回は手を入れていません。
- TUKUYO は外しました（ご要望）。
  - これまでは、戦っているモブ1体ごとに10秒おきに TUKUYO のサービス（ポート8022）へ問い合わせ、その答えでモブの構え（攻めるか守るかなど）を変えていました。
  - 今は、ORORから TUKUYO には何も問い合わせません。古いワールドの設定に「tukuyo = true」が残っていても同じです。
  - インポート用の zip からも、TUKUYO のサービスと説明書を外し、新しいワールドの設定を「tukuyo = false」にしました。
  - ローカルAI（Qwen、ポート8023）の会話は残しています。プレイヤーがモブに話しかけたときだけ使い、サービスを起動していなければ何もしません。

## 5. 王宮の入口や村の建物が壊れている・完成していない（ご報告）
- 主な原因は、村人の小屋づくりでした。
  - 村人は、村の中心から10〜28ブロックの輪の中で、空いている場所ならどこにでも5×5の小屋を建て始めていました。王宮の前庭、通り、扉の前も対象でした。
  - 板材を待つ間は建てかけのまま止まります。それで、入口が塞がれたり、建てかけの建物が残ったりしていました。
- 直したこと：
  - 王都の中では、小屋を建てません。建てかけの小屋は、建てるのをやめます。
  - 村では、扉・ベッド・鐘・作業台・道・柵の門から4ブロック以内には、小屋を建てません。
  - コマンド `/oror citadel clearhuts` を追加しました（権限レベル2）。
    - 実行した人の周り256ブロックの、王都のチャンクから、053より前に建てられた小屋を取り除きます。
    - 取り除くのは、元の王都の設計で「空気」の場所にある、小屋の材料（板材、丸石、木の扉、ベッド、松明）だけです。王国の建物と、プレイヤーがほかの材料で建てたものは残ります。
- そのほかの守り：
  - 村の鉱夫は、地下だけを掘ります（空が見える場所と、王都の地面より上は掘りません）。
    - 方解石（王都の白い壁）と草ブロックを、掘る対象から外しました。
    - これまでは、作業場から鉱脈までの間にあるものを、作業場の床から2ブロック上まで掘っていました。
  - 王都と村の中の爆発は、プレイヤーかモンスターが起こしたもの以外では、ブロックを壊しません。
    - 王国の砲台や戦車、兵や村人の銃と魔法は、当たった相手には効きますが、守っている町は壊しません。
    - 王都と村の外では、これまでどおりブロックが壊れます（049のご要望）。
- 生成のときの修正：
  - 隣のチャンクの飾り（木、岩、氷、ジオードの結晶、巨大キノコなど）が王都のチャンクにはみ出した分を、取り除くようにしました。
    - これまでは草花だけを、地面の近くだけ取り除いていました。今は、王都の設計にない自然のブロックを、10ブロック内側まで、設計の一番上の高さまで戻します（丘の上の木が、王宮の上の階まで伸びていたことがありました）。
  - 地下の迷宮の壁に、隣のチャンクのジオード（アメジストの晶洞）、溶岩、石が食い込んでいたのも、元に戻すようにしました。
    - 地下では、王国が造ったブロック（迷宮の壁など）だけを戻します。設計で自然のままの岩はそのままです。
    - ジオードの中の空洞を埋めるのは、まだ誰も入っていないチャンクだけです（プレイヤーが掘った穴は埋めません）。
    - 地下の黒曜石（宝物庫）と丸石（坑道）は、自然の岩ではなく王国が造ったものとして扱い、元に戻します。溶岩が流れ込んでいた場所も、まだ誰も入っていないチャンクなら戻します。
- CIで、生成した王都を元の設計とブロック単位で照合しました。
  - 王都の中心の289チャンクで、10,156,870ブロックを照合しました。
  - 違っていたのは、2回目が725ブロック、地下の修正のあと（4回目）が152ブロック、黒曜石と丸石の修正のあと（5回目）が107ブロック（0.001%）でした。王宮の近く（玉座から70ブロック以内）では、3〜4ブロックでした。
  - 2回目の違いのほとんどは、地下40ブロックほどの迷宮の壁に食い込んだジオードと溶岩でした（上の修正で直りました）。5回目に残ったのは、王都の端の砂や海草などです。
  - つまり、新しく作った世界では、王宮の入口も建物も設計どおりに生成されていました。
- 入口が塞がれていたり、建物が完成していなかったりしたのは、次のどちらかと考えています。
  - 村人の小屋：上で直しました。すでに建ってしまったものは `/oror citadel clearhuts` で取り除けます。
  - 古い版で生成された王都：チャンクを読み込むと、王都の修正が自動で当たります（進み具合は `/oror citadel update` で見られます）。
  - それでも直らない場所があれば、座標（F3で表示されるXYZ）かスクリーンショットを送ってください。その場所を照合して直します。
