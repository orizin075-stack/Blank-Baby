# Character design sheets

`sheets/NN_*.jpg` are the user's 37 Minecraft-style character design sheets (front three-quarter view, back view,
close-ups). The mob models are rebuilt from them with `tools/mc/design_build.py`: geometry per character in
`design_chars.py`, and the texture is the sheet itself projected onto the model (`designfig.py`, `sheets.py`).
