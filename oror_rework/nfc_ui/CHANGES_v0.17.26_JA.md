# OROR War × Nightfall 0.17.26 — 2つの 0.17.25 をまとめた版

Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21。0.17.24 から別々に作られた 0.17.25 が2つあります。

- **画面の 0.17.25**（CHANGES_v0.17.25_JA.md）：NightfallCraft と同じタイトル画面・メニュー・HUD、満腹度の廃止と
  防御力の表示、0.17.24 の監査で見つけた不具合の修正。
- **戦闘操作の 0.17.25**（README_0.17.25_JA.md）：武器を持つだけで戦闘操作になる、紫黒になっていた Nightfall の武器の
  見た目の修正。

0.17.26 は、戦闘操作の 0.17.25 の JAR を土台にして、画面の 0.17.25 の変更をすべて載せ直したものです。

## 戦闘操作の 0.17.25 から取り込んだもの

- **武器の見た目**：紫黒（画像なし）で表示されていた Nightfall の派生武器11点（nf_shortsword_e、exsiliumgladius_e、
  meen_spear_e、air_tachi_e、arc_tachi、crimson_moon_e、crescent_moon_e など）を元の武器の画像につなぎ直し、
  旗（flag_bearer）のインベントリ表示と Excalibur の画像の参照も直っています。元の画像は変えていません。
- **武器を持つだけで戦闘操作**：R キーでの切り替えなしで、武器を持てば攻撃・ガード・パリィができます。
  NightfallCraft で戦闘用とされていた武器433件に加え、Epic Fight の武器設定を持つ武器（素手と採掘道具を除く）が対象です。

## 0.17.26 で変えたところ

- **自動の戦闘操作は「持ち替えた時」と「ワールドに入った直後」だけ**：戦闘操作の 0.17.25 は、武器を持っている間
  サーバーとクライアントの両方で毎 tick 戦闘操作に戻していたため、R キーで通常操作に切り替えても即座に戻され、
  武器を持ったまま通常操作にできませんでした。0.17.26 では、武器に持ち替えた時と、ワールドに入って最初の3秒間
  （通常操作のまま保存されたワールド）にだけ戦闘操作にします。R キーで通常操作にすれば、次に持ち替えるまでそのままです。
- **HUD**：戦闘操作の 0.17.25 は 0.17.22 からの簡易表示（標準ホットバーとハート＋HP の数字）のままで、スタミナ・
  ガード・パリィ・マナの表示が出ていませんでした。0.17.26 は画面の 0.17.25 と同じく NightfallCraft の HUD
  （1列のホットバーの上に HP・防御力・スタミナ・マナ。満腹度の場所に防御力）です。簡易表示に戻すには
  config/oror-nightfall-patch.properties の compactHud を true にします。
- **Epic Fight の設定**：カメラなどは NightfallCraft の値です（画面の 0.17.25 と同じ）。戦闘用の武器一覧は、
  NightfallCraft の433件のうちこのパックにある387件と、OROR の遺物武器などを合わせた439件です（パックにない46件は
  設定ファイルには入れず、パックに追加された場合は持った時に戦闘用として扱います）。

## 画面の 0.17.25 から引き継いでいるもの（詳しくは CHANGES_v0.17.25_JA.md）

- 満腹度なし（Hunger Strike。食べ物は HP を回復）、HUD の満腹度の場所に防御力。
- NightfallCraft のタイトル画面（標準ロゴ・スプラッシュ・バージョン表記なし、左下のアイコン列）、起動中・ワールド
  読み込み中の画面、TCR Core のボタン・タブ・区切り線・月夜の背景のメニュー。SETUP_NIGHTFALL.cmd が TCR Core から
  画像33枚を取得します。
- 0.17.24 の不具合修正：ガードがパリィに戻され続ける、Nightfall／Indestructible がないと起動できない、村人が敵に
  気づかない、魔法武器の自動詠唱がマナ・クールダウンを無視、パリィ通知の安全化、TCR の5アイテムの名前。
- リソースパックは最初すべて無効（NightfallCraft と同じ。「設定 → リソースパック」から有効にできます）。
- シェーダー（Iris）は、Create Aeronautics が必須とする Sodium と組み合わせられないため入れていません。

## 導入

- **新しいプロファイル（おすすめ）**：`OROR_War_Nightfall_v0.17.26_Import.zip` を展開せずに CurseForge へインポートし、
  起動前にプロファイルのフォルダーで `SETUP_NIGHTFALL.cmd` を1回実行します（Nightfall・御剣・画面の画像を取得）。
- **0.17.24 か、どちらかの 0.17.25 のプロファイルを使い続ける場合**：ゲームを終了し、`mods` の
  `oror_supreme_bosses-0.17.2x.jar` を外して `OROR_War_Nightfall_v0.17.26_Patch.zip` の `mods` の中身を入れ、`config` と
  `oror-install` をプロファイルへ上書きします。画面の 0.17.25 で増えた MOD（Hunger Strike・画面関係）は Import でしか
  入らないため、0.17.24 と戦闘操作の 0.17.25 からは新しいプロファイルをおすすめします。
