# TUKUYO v1022.5 Fusion + claude-patch3

v1022.5 Fusion の上に積んだ改良です。Fusion の中身はすべてそのまま残しています。

- 復元の強化
- 多段推論・仮説比較・メタ推論
- patch1/2 の取り込み
- Soul・Heart・鍵・継承

狙いは patch2 と同じで、次の 2 点です。

- LLM 無しで、証明つきで答えられる範囲を広げる。
- 間違ってるのに確定扱いの答えを 0 に保つ。

## 1. 追加した能力（すべて LLM 不要、証明は `proofs.check` が質問文から作り直して照合）

### A. 量・時間・暦（新規 `qtime.py`）

| 種類 | 例 |
|---|---|
| 単位換算 | 「3.5kmは何m？」「2時間15分は何分？」「90分は何時間何分？」"How many minutes are in 3 hours?" |
| 時刻の計算 | 「午前9時40分から50分後は？」 |
| 曜日 | 「今日は月曜日。10日後は何曜日？」 |
| 暦 | 「2026年10月5日の30日後は？」「2000年1月1日は何曜日？」（グレゴリオ暦で計算） |
| 割合 | 「5000円の2割引き」「15%引き」「2割増し」「25%は？」 |
| 決まった数 | 「1ダースは何個？」 |

扱わないもの：

- 日付をまたぐ時刻
- 「1年は何日」（うるう年で答えが変わるため）

### B. 文章題の型を追加（新規 `wordprob2.py`、`wordprob.py` を拡張）

| 型 | 例 |
|---|---|
| **方程式**（1 つの未知数） | 「ある数を2倍して3を足すと11」。操作を逆にたどって解き、**答えを元の式に戻して確認**してから返します |
| 1 回分×回数／全体÷1 回分 | 「1日に15ページずつ、150ページは何日」「毎月800円ずつ6か月」 |
| 1 人分で配る | 「60個を1人5個ずつ配ると何人」 |
| 全体−一部 | 「そのうち男子は17人。女子は？」 |
| 差 | 「白い花は赤い花より何本多い？」 |
| それぞれ N 個ずつ | 複数の品を同じ数ずつ買う |
| おつり | 「2000円で…」型の支払い |
| 比較 | 間に目的語が入る形（「姉はビー玉を35個持っています」） |
| 語彙 | 入れる・飛び立つ・取り出す・切り取る、「〜から切る」 |
| 英語 | "N times as many / twice as many"、"costs N dollars each"、"15 people left / 8 more came"、"share N among M" |

在庫の文で「より多く持っている」は出来事ではなく比較なので、比較の型で答えるようにしました。ただし、知らない出来事の動詞（売る・貸す など）は、今までどおり先生から学ぶ領域に残しています。

### C. 記憶質問（`kqa.py` を書き直し）

- **多段の参照**ができるようになりました。
  - 「XのYのZは？」「XのYはいつ開業した？」：1 段ずつ、実体名の完全一致で最大 3 段たどります。
  - 英語の "the city founded by Captain Rhee" 型も 1 段たどれます。
- 言い換えを増やしました（何人入れる→収容人数、何時から開いている→営業時間、トップ→〜長 など）。
- 知らない属性を聞かれたら、**何を覚えているかを言います**。例：「『港南大学』について覚えているのは創立・学長・所在地です」。

### D. 論理（`logic2.py` を拡張）

- 「〜すると」の条件文を読めるようにしました（「雨が降ると傘をさす」）。
- 「犬か猫のどちらかを飼っている」のように、述語を共有する選言を読めるようにしました。
- 「傘をさす／さしていない」「着る／着た」のような活用の揺れを、同じ言葉として扱います。
- 英語でできるようになったこと：
  - 代名詞（名前が 1 人だけのとき）
  - "No X can Y"
  - "Either A or B won"
  - 不規則動詞の過去形
- **反対語の大小関係**も扱います。例：年下で書かれた前提に「一番年上は？」、older で書かれた前提に "Who is youngest?"。

### E. 会話で覚える

- チャットで「覚えて：〇〇の定休日は木曜日である。」と言うと、記憶（knowledge store）に追記します。記録元は `source=chat` です。
- 追記したことは、すぐ質問に使えます。

## 3. 使い方

```bash
A=../deliverables/TUKUYO_v1022_5_patch3_TRUST_ANCHOR.txt
python3 -B tools/verify_release.py . --trusted-pubkey-file $A
python3 -B run_tukuyo.py --runtime-trust-file $A --data D init
python3 -B run_tukuyo.py --runtime-trust-file $A --data D think -- "ある数を2倍して3を足すと11になる。ある数は？"
python3 -B run_tukuyo.py --runtime-trust-file $A --data D chat      # 「覚えて：…」で記憶に追加
```

署名と信頼アンカーについて：

- 署名は patch1/2 と同じパッチ鍵（`22jzm2l8…`）です。
- 既存の v1022.5 個体を動かす場合は、`runtime-trust-rebind` で旧アンカーを明示してください。旧アンカーは Fusion の受領書の鍵（`SNYPV94/…`）です。
- 採用する場合は、ご自身の鍵で署名し直してください。

## 4. 限界

- 文章の読み取りは、今も有限の型です。未見 C で文章題を取りこぼしたのは次のような問題です。
  - 「〜ずつ…何分」
  - 「たばにすると、いくつ」
  - 「そのうち〜が飛んでいきました」
  - 否定を含む全体−一部
  - 「ちがいは」
  - 「2週間で」の換算
  - 「〜を買うと残りは」
  - "holds 6 eggs"
  - "cuts off"
  - 「明日は晴れた」のような時の語
  - "the engineer who designed…" 型の英語の多段参照
- 平均・最小公倍数・面積・数列などは、まだ型がありません。
- 「〜を求めましょう」のような命令形の問いは、方程式の型が読めていません。
- 本物の LLM での効果は、今回も測っていません。`tools/llm_eval.py` で測ってください。
