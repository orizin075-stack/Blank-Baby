# TUKUYO v991 — Grounded Homeostatic Evaluation

v991は、v990で観測された環境結果を生命維持状態へ因果接続し、valenceとimportanceを呼び出し側から受け取らず、自身の状態変化から導出します。

内部状態は energy / integrity / fatigue / threat / reserve / uncertainty / goal_achievement。行動後のhomeostatic burden変化、実測resource、hazard、goal progress、information gainからgrounded utilityを後計算し、その値からvalenceを導きます。同じ行動でも状況により正負が変化します。

導出したvalenceは既存heart/soul loopへ入力されるため、環境結果→内部状態→感情評価→意味→魂遷移まで接続されます。これはシミュレーション身体の機能モデルであり、主観的感情や文字どおりの生命を意味しません。
